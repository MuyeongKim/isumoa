# <img src="docs/brand/isumoa-repository-icon.png" width="40" height="40" alt=""> 이수모아

**법정교육 이수증을 모아 검수하고, 직원별 이수 현황과 기관 제출 자료를 만드는 Windows 프로그램입니다.**

EXE를 실행해 설치하면 됩니다. Node.js나 OCR 구성요소를 따로 설치할 필요가 없으며, 화면은 Edge·Chrome 같은 브라우저에서 열립니다. 수료증 판독과 업무 자료 보관은 사용하는 PC에서 이루어집니다.

## Windows 설치 파일 받기

현재 배포 버전은 **0.5.8**입니다. **Windows 10·11 64비트**, 설치 시 디스크 여유 공간 **2GB 이상**이 필요하며 자료가 쌓이면 추가 공간이 필요합니다.

|---|---|

| [ZIP 설치판](https://github.com/MuyeongKim/isumoa-releases/releases/download/v0.5.8/isumoa-setup-0.5.8-win-x64.zip) | 압축을 푼 뒤 `설치.bat`을 실행합니다. |
| [설치 안내](https://github.com/MuyeongKim/isumoa-releases/releases/download/v0.5.8/PC-install-guide-0.5.8.md) | 설치·실행·자료 위치·업데이트 방법 |

설치 파일은 **GitHub Releases에서만 배포**합니다. GitLab에서도 위의 같은 링크를 사용하며, **GitHub 로그인 없이 다운로드**할 수 있습니다.

## 설치하고 처음 사용하기

1. **Windows 설치 EXE**를 내려받아 실행합니다.
2. 설치 후 바탕화면의 **이수모아**를 열고 기관명·관리자 계정을 직접 설정합니다.
3. **직원 명단 → 일괄 등록 → 빈 양식 다운로드**에서 받은 엑셀을 채워 올립니다.
4. **교육 기준**에서 기본 교육 16개와 연간 시간을 기관 지침에 맞게 확인합니다. 개인정보보호 기본값은 연 1시간입니다.
5. **수료증 올리기**에 PDF·사진 또는 이들을 모은 ZIP을 올립니다.
6. **검수함**에서 원본과 직원·교육명·날짜·시간·증서번호를 대조한 뒤 확정합니다.
7. **이수 현황**을 확인하고 **내보내기**에서 엑셀·PDF·제출 양식을 받습니다.

자세한 조작 방법은 [사용설명서](docs/사용설명서.md), 설치 관련 내용은 [PC 설치 안내](docs/PC설치안내.md)를 참고하세요.

## 0.5.8에 반영된 내용

- **설정 → 검수 규칙:** 공식 규칙 최신 확인, 사용자 규칙 추가·수정, JSON 가져오기·내보내기, 변경 미리보기와 이전 버전 복원을 제공합니다. JSON 문법을 직접 편집하지 않아도 됩니다.
- **설정 → 로컬 AI(선택):** 같은 PC의 Ollama에 이미 설치된 로컬 생성 모델을 연결할 수 있습니다. 기본은 꺼짐이며 LLM이 없어도 기존 OCR·규칙 검수와 내보내기를 사용할 수 있습니다.
- 검수함의 **추가 검토**에서 규칙 재검토·AI 의견을 비교하고 선택한 항목만 편집값에 반영합니다. 자동 저장·확정하지 않으며 기존 확정 기록과 기관 교육 기준을 바꾸지 않습니다.
- 스캔 OCR에도 사용자 인식 항목 이름을 적용합니다. 프로그램 업데이트 준비 완료 표시 시점의 경합을 수정했습니다.
- 미충족 상태의 명단 출력과 주제 충돌·중복 확정 차단을 유지합니다.

## 기관 제출 양식과 최종 명단

수료자 명단(16시트)과 같은 형식의 기관보고 양식은 **기준 미충족이나 검수 대기가 있어도 현재 확정된 내역으로** 받을 수 있습니다. 검수 대기·제외 건은 포함하지 않습니다. 부분이수는 비고에 표시하며 이수인원은 교육별 기준을 충족한 직원만 셉니다.

2026년 양식의 소속·부서·계급·성명·교육기관·과정·시간·수료일·수료증 번호를 채우며 **현원은 빈칸**으로 둡니다. 같은 직원의 여러 증서는 각각 기록하고 이수 인원은 한 명으로 계산합니다. 부서별 파일로 나눌 때도 선택한 직원 범위만 포함합니다.

제출 양식은 `.xlsx`로 올립니다. 옛 엑셀 `.xls`나 매크로 파일 `.xlsm`은 Excel에서 일반 `.xlsx`로 저장해 올려 주세요. 기관별 적용 대상과 교육 기준은 사용 전에 확인하세요.

## 업데이트와 자료 보관

- **0.5.0 이상:** 설정 → 업데이트에서 새 버전 확인·다운로드·설치를 진행합니다. EXE를 직접 실행해 업데이트할 수도 있습니다.
- **0.4.3 이하:** 최신 EXE를 직접 실행해 한 번 업데이트하세요.
- 업데이트 전 **설정 → 백업·보관 → 지금 백업**이 정상 완료되는지 확인하세요. 설치 전에도 백업을 수행하며 설치·기동 실패 시 이전 프로그램과 자료 복구를 시도합니다.
- 기존 기관 정보·직원·수료증·사용자 지정 교육 기준은 유지합니다. 백업은 다른 디스크에도 보관하는 것을 권합니다.

업데이트 확인·다운로드에는 GitHub 인터넷 연결이 필요합니다. 원본 PDF·사진, DB·백업은 앱 자체에서 자동 암호화하지 않으므로 PC 계정·디스크·백업 접근 권한을 관리하세요. 사진과 스캔본은 글자를 잘못 읽을 수 있어 자동으로 채운 값도 원본과 대조해야 합니다.

## 검증과 시범운용 범위

0.5.8 소스의 **자동검증 461개와 타입 검사·빌드**를 통과했습니다. 별도 가상 DB의 실제 화면에서 규칙 편집·다운로드·가져오기·복원과 로컬 모델 추가 검토를 확인했습니다. 모델별 정확도나 Windows 실행 성능을 보장하는 결과는 아닙니다. 설치본 구성과 검증 범위는 릴리스 검증 요약에 기록합니다.

**미서명 부서 시범운용용**입니다. Windows 실기기 설치·실제 업데이트·Windows Excel/한셀 열기·인쇄·기관 백신 검사는 별도 미확인입니다. 먼저 시험용 PC와 복사한 자료로 [릴리스 검증 요약](https://github.com/MuyeongKim/isumoa-releases/releases/download/v0.5.8/validation-report-0.5.8.md)의 항목을 확인하세요.
