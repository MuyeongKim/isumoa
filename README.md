# <img src="docs/brand/isumoa-repository-icon.png" width="40" height="40" alt=""> 이수모아

**법정교육 수료증을 검수하고 직원별 이수 현황과 기관 제출 자료를 만드는 Windows 프로그램입니다.**

설치 파일에 판독에 필요한 구성요소가 들어 있습니다. 프로그램을 열면 브라우저에서 명단을 등록하고 수료증을 검수할 수 있습니다.

![가상 자료로 원본과 인정 교육을 대조하는 검수함](docs/images/review.webp)

## 다운로드·접속 주소

공공 GitLab 릴리스에서 Windows 64비트용 `isumoa-setup-0.5.12-win-x64.exe`를 받으세요. GitLab에 로그인한 뒤 프로젝트를 열람할 권한이 있어야 다운로드할 수 있습니다. [공공 GitLab v0.5.12 릴리스](https://gitlab.aigov.go.kr/tenmoo/isumoa/-/releases/v0.5.12) · [설치 EXE 바로 받기](https://gitlab.aigov.go.kr/tenmoo/isumoa/-/package_files/4036/download)

Windows EXE의 SHA-256은 `a691e7e825f7c8b0aa8f9c1441288e8b947433a2c6903307d47e8f72b02e9021`입니다.

압축 설치판과 모의자료는 같은 버전의 공개 배포본을 사용하세요. [Windows 설치 ZIP(GitHub)](https://github.com/MuyeongKim/isumoa-releases/releases/download/v0.5.12/isumoa-setup-0.5.12-win-x64.zip) · [가상 모의자료 ZIP(GitHub)](https://github.com/MuyeongKim/isumoa-releases/releases/download/v0.5.12/demo-samples-0.5.12.zip)

이수모아를 실행하면 설치한 PC의 브라우저에서 `http://127.0.0.1:47210`이 열립니다.

## 해결하려는 문제와 개발 경위

이수모아는 2026년 공공 AI 대전환 챌린지 세션 1 자유주제로 출품합니다. Windows 설치판과 소스코드, 구동안내서, 실제 앱 시연영상, 가상 모의자료를 준비했습니다.

수료증은 발급기관마다 양식이 다릅니다. 여러 장을 한 PDF로 스캔해 제출하면 담당자는 한 장씩 열어 이름, 교육명, 날짜, 시간을 옮겨 적고 직원 명단과 교육 기준을 대조해야 합니다. 중복으로 들어온 수료증이나 비슷한 이름의 교육도 따로 확인합니다.

이수모아는 이 과정에서 반복해서 입력하고 자료를 모으는 일을 줄이기 위해 만들었습니다. 먼저 수료증의 글자를 읽어 교육 기준과 대조합니다. 담당자는 검수함에서 원본을 보며 어떤 교육으로 인정할지 결정합니다. 확정한 자료는 직원별 이수 현황과 기관 제출 자료로 이어집니다. 현재는 부서 시범운용 단계입니다.

## 주요 기능

| 업무 | 기능 |
|---|---|
| 직원·부서 | 빈 엑셀 양식, 직원 일괄 등록, 선택 삭제와 복원 |
| 교육 기준 | 기본 교육 16개, 기관별 기준 설정, PDF·HWPX·사진에서 초안 등록 |
| 수료증 검수 | PDF·사진·ZIP 판독, 검색, 정상 일괄 확정, 선택 제외와 복원 |
| 인정 확인 | 주제 충돌과 동일 수료증 중복 확정 차단, 불명확한 범위 표시 |
| 현황·출력 | 미이수 필터, 16시트 명단과 제출 양식, 합본 PDF, 파일명 지정 ZIP |
| 규칙·관리 | 규칙 JSON 편집과 복원, 선택형 로컬 AI, 백업과 업데이트 |

| 브라우저 | Edge 또는 Chrome |
| 필요 소프트웨어 | 설치판에 Node.js, OCR 엔진, 한국어 모델 포함 |

| 인터넷 | 배포판과 업데이트 다운로드에 사용. 기본 업무는 로컬 처리 |

## 설치·실행 방법

1. 공공 GitLab에서 Windows EXE를 받습니다. 다운로드한 폴더에서 PowerShell을 열고 `Get-FileHash .\isumoa-setup-0.5.12-win-x64.exe -Algorithm SHA256`을 실행합니다. 결과가 위에 적힌 SHA-256과 같으면 EXE를 실행하세요. ZIP 설치판을 받았다면 압축을 모두 풀고 `설치.bat`을 실행합니다.
2. 바탕화면의 **이수모아**를 열고 기관명과 관리자 계정을 만듭니다. 기존 업무 자료와 분리된 환경에서 모의 시연을 진행하세요.
3. **직원 명단 → 일괄 등록 → 빈 양식 다운로드**의 엑셀을 채워 올리고 미리보기를 확인합니다.
4. **교육 기준**에서 16개 기본 교육을 기관 지침에 맞춥니다. 개인정보보호 기본값은 연 1시간입니다.
5. **수료증 올리기**에서 PDF, 사진 또는 ZIP을 고릅니다.
6. **검수함**에서 원본과 직원, 인정 교육, 날짜, 시간, 증서번호를 대조해 확정하거나 제외합니다.
7. **이수 현황**을 확인하고 **내보내기**에서 종류, 범위, 다운로드 사유를 골라 받습니다.

업무 자료는 `%LOCALAPPDATA%\isumoa`에 저장합니다. **설정 → 백업·보관**에서 백업을 만들 수 있습니다. 복원 순서는 설치 안내를 참고하세요. [PC 설치 안내](docs/사용자/PC설치안내.md)

시범운용 배포본에는 코드 서명이 없습니다. SmartScreen이나 기관 보안 프로그램에서 설치를 막으면 파일 출처와 SHA-256, 차단 화면을 정보화 담당자에게 전달해 확인받으세요.

## AI 구성과 LLM 설정

수료증은 설치한 PC에서 kordoc과 한국어 PP-OCRv5로 읽습니다. 기본 OCR을 실행할 수 없으면 tesseract.js로 판독합니다. 읽은 값은 등록한 규칙과 대조하며, 최종 확정은 담당자가 합니다.

판독부터 출력까지는 설치판만으로 사용할 수 있습니다. 검수 중 AI의 제안이 필요한 경우 로컬 LLM을 켤 수 있습니다. 기본 설정은 꺼짐이며, 사용할 생성 모델은 별도로 준비합니다.

1. 같은 PC에서 Ollama와 사용할 로컬 생성 모델을 준비합니다.
2. **설정 → 로컬 AI(선택)**에서 `http://127.0.0.1:11434`의 연결 테스트와 모델 목록을 누릅니다.
3. 모델을 선택하고 사용을 켜서 저장합니다. 모델 교체도 같은 목록에서 합니다. 기본 연결은 API 키를 사용하지 않습니다.
4. 검수 대기에서 **추가 검토 → AI 추가 검토**를 요청하고 제안과 원문 근거를 대조합니다.
5. 반영할 항목을 선택해 편집값에 반영한 뒤 임시 저장하거나 확정합니다.

## 모의데이터로 시연하기

가상 모의자료 ZIP을 풀면 직원 명단과 수료증이 나옵니다. 업무 자료와 분리한 시연 환경에서 명단을 먼저 올린 뒤 수료증을 검수해 보세요.

| ZIP 구성 | 용도 |
|---|---|
| `직원명단_2026.xlsx` | 직원 120명, 8부서 일괄 등록 |
| `이수증/스캔묶음_재무과.pdf` | 스캔 묶음 40쪽 |
| `이수증/개별/*.pdf` | PDF 10개. 묶음과 합계 11개 파일, 50쪽 |
| `정답.json` | 판독 결과 비교용. 프로그램에 올리는 자료에서 제외 |
| `모의자료_사용안내.md` | 가상 자료의 구성과 확인 순서 |

1. **직원 등록**. **직원 명단 → 일괄 등록**에서 `직원명단_2026.xlsx`를 올리고 미리보기를 확인한 뒤 직원 120명·8부서를 등록합니다.
2. **판독·검수**. **수료증 올리기**에서 PDF 11개를 올립니다. **검수함**에서 폭력예방교육 20건을 검색해 원본과 대조합니다. 비수료 자료 2쪽을 일괄 제외하고 정상 자료를 모두 확정하면 **확정 48건, 제외 2건, 검수 대기 0건**입니다.
3. **중복·충돌 확인**. 확정한 파일을 다시 올려 중복 건너뛰기를 확인합니다. 주제 충돌이 표시되면 원본을 확인해 교육 연결을 바로잡습니다.
4. **현황·출력**. **이수 현황**의 대상은 휴직 1명과 파견 1명을 뺀 **118명**입니다. 현황 칸에서 근거 수료증을 열고 **내보내기 → 수료자 명단(16시트)**에서 XLSX를 받습니다. 합본 PDF와 개별 ZIP도 내보낼 수 있습니다.

### 실제 앱 시연영상과 검증 범위

제출용 **2분 41초 MP4**에서는 이수모아 0.5.12에 가상 직원 명단을 등록하고 수료증을 검수한 뒤 16시트 XLSX를 내려받습니다. 촬영은 macOS 개발 환경에서 진행했습니다. 스캔본 40쪽은 로컬 OCR로 읽고 글자층이 있는 10쪽에서는 텍스트를 추출했습니다. 내려받은 XLSX는 Numbers에서 열었습니다.

- **미확인**. Windows 10/11 실기기 설치·실행·업데이트, Excel/한셀 열기·인쇄, 기관 백신 결과
- **미실시**. 직원 독립 사용과 엑셀 수기 작업의 소요 시간 비교, 실제 2종 LLM 비교

## 자료 처리와 제약사항

- OCR 결과는 원본 대조가 필요합니다. 로컬 AI는 개인정보를 가린 일부 텍스트로 의견을 제안하며, 가림과 정확도를 보장하지 않습니다. 불명확한 표는 AI 요청을 보류합니다.
- DB와 원본, 백업은 앱 자체 암호화가 없습니다. PC와 폴더 권한을 관리하고 백업을 별도 보관하세요. 모의자료는 업무 자료와 섞지 않습니다.
- 업데이트 확인과 다운로드는 GitHub에 통신합니다. 자동 확인은 기본 꺼짐이며 업무 자료를 보내지 않습니다. 자동 다운로드와 설치, 규칙 적용은 하지 않습니다.

## 폴더 구조

```text
server/        # API, DB, OCR, 검수와 집계
web/           # 화면과 프로그램 내 사용설명서
shared/        # 공통 타입과 규칙
tests/         # 단위·API·Windows 유지보수 검사
scripts/       # 샘플 생성, 평가, 빌드와 문서 검사
deploy/        # 설치·실행·업데이트·제거 스크립트
vendor/        # 오프라인 OCR 모델과 구성요소 고지
docs/          # 안내 문서, brand/images/promo/licenses 자료
├─ 사용자/     # 설치와 업무 사용법
├─ 관리자/     # 서버·보안·운영 안내
├─ 개발/       # 개발 안내, 조사 자료와 예제
├─ 검증기록/   # 회귀 검사와 릴리즈 기록
└─ session1/   # 공모 제출 준비와 실측 절차
samples/       # 저장소에는 정답만 보관. PDF는 생성하거나 모의자료 ZIP 사용
```
