# 법정교육 이수증 종합 플랫폼 — 정보화 담당 확인 요청

서무가 걷은 법정교육 이수증(PDF)을 한꺼번에 올리면, 기관 자체 AI 서버가 이수증 내용을 읽고 직원·교육별로 분류해 주는 내부 업무 시스템입니다. 내부망 서버 1대에 설치해 쓰려고 합니다. 설치와 연동을 위해 아래 사항을 확인해 주시면 감사하겠습니다.

## 1. 기관 자체 AI 서버

| 확인할 내용 | 답변 |
|---|---|
| API 형식이 OpenAI 호환(`/v1/chat/completions`)인가요? 아니라면 어떤 형식인가요? | |
| 접속 주소와 인증 방식 (API 키, 헤더 등) | |
| 쓸 수 있는 모델 이름 | |
| 이미지 입력(이수증 사진·스캔본을 직접 읽기)을 지원하나요? | |
| 한 번에 보낼 수 있는 글자 수(컨텍스트 길이) | |
| 동시에 보낼 수 있는 요청 수, 시간당 사용 한도 | |
| 이 시스템에서 개인정보(성명·생년월일·소속)가 담긴 이수증 내용을 보내도 되나요? 승인 절차가 있나요? | |
| 생각 과정(thinking)을 끄는 방법 (예: vLLM+Qwen은 `chat_template_kwargs.enable_thinking=false`) | |

AI 서버로는 이수증 한 장의 내용만 보내고, 직원 명단은 보내지 않습니다.
인터넷이 되는 환경이라면 외부 AI(Claude API)도 쓸 수 있게 만들어 두었지만, 기본은 꺼져 있고 관리자가 개인정보 전송을 명시적으로 허용해야 켜집니다. 설정 파일(`allowExternalAi: false`)로 아예 막을 수도 있습니다.

## 2. 설치할 서버

| 확인할 내용 | 답변 |
|---|---|
| 운영체제와 버전 (Windows Server 2016 이상 또는 Linux — glibc 2.28 이상, 예: RHEL 8 / Ubuntu 20.04 이상) | |
| CPU·메모리·디스크 여유 공간 (권장: 2코어, 4GB, 이수증 보관용 20GB 이상) | |
| 프로그램을 서비스로 등록할 권한 (Windows 서비스 또는 systemd) | |
| 사용할 포트 번호 (기본 8080)와 방화벽 개방 범위 | |
| HTTPS 인증서를 쓸 수 있나요? (리버스 프록시 또는 인증서 파일) | |
| 백업 방식 (데이터 폴더 1개를 정기적으로 복사하면 됩니다) | |

설치본에는 실행에 필요한 Node.js가 함께 들어 있어 별도 프로그램 설치나 인터넷 연결이 필요 없습니다.

## 3. 직원 PC와 자료

| 확인할 내용 | 답변 |
|---|---|
| 직원 PC 웹 브라우저 종류와 버전 (최신 Chrome 또는 Edge 필요) | |
| 인사 명단 파일 형식 (xlsx / xls / csv)과 들어 있는 열 (사번, 성명, 부서, 직급, 생년월일 등) | |
| 개인정보 처리 시스템으로서 보안성 검토가 필요한가요? 필요하다면 절차와 제출 자료 | |

## 4. 이 시스템의 보안 관련 사항

- 외부 인터넷에 접속하지 않습니다. 화면·글꼴 등 모든 파일을 서버에서 직접 제공합니다. (관리자가 외부 AI를 허용한 경우에만 그 AI 서버에 접속합니다.)
- 서무는 담당 부서의 직원과 이수증만 볼 수 있습니다 (서버에서 권한을 확인).
- 로그인 5회 실패 시 10분 잠금, 60분 동안 사용하지 않으면 자동 로그아웃됩니다.
- 비밀번호는 복원할 수 없는 방식(scrypt)으로 저장합니다.
- 로그인·계정 권한 변경·명단 반영 등 주요 작업을 감사 로그에 남깁니다.
- 주민등록번호는 저장하지 않습니다 (명단에 있어도 생년월일만 저장).
