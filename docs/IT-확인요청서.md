# 이수모아(법정교육 이수증 종합 플랫폼) — 정보화 담당 확인 요청

서무가 걷은 법정교육 이수증(PDF·스캔본)을 한꺼번에 올리면, 서버 안의 OCR로 이수증 내용을 읽어 직원·교육별로 분류해 주는 내부 업무 시스템입니다. 내부망 서버 1대에 설치해 쓰려고 합니다. 설치를 위해 아래 사항을 확인해 주시면 감사하겠습니다.

이수증 내용은 서버 밖(AI 서버·인터넷)으로 보내지 않습니다. 스캔본 OCR은 설치본에 들어 있는 kordoc(MIT 라이선스)과 PP-OCRv5 한국어 모델(Apache-2.0)로 서버 CPU에서 처리합니다.

## 1. 설치할 서버

| 확인할 내용 | 답변 |
|---|---|
| 운영체제와 버전 (Windows Server 2016 이상 또는 Linux — glibc 2.28 이상, 예: RHEL 8 / Ubuntu 20.04 이상, x64) | |
| Windows라면 Visual C++ 재배포 패키지(x64)가 설치되어 있나요? (스캔본 OCR 엔진이 씀. 없으면 정확도가 낮은 대체 OCR로 읽음) | |
| CPU·메모리·디스크 여유 공간 (권장: 2코어, 4GB, 이수증 보관용 20GB 이상) | |
| 프로그램을 서비스로 등록할 권한 (Windows 서비스 또는 systemd) | |
| 사용할 포트 번호 (기본 8080)와 방화벽 개방 범위 | |
| HTTPS 인증서를 쓸 수 있나요? (이 서버에 PEM/PFX 인증서 파일을 두거나, 기관 리버스 프록시가 HTTPS를 맡음) | |
| 백업을 둘 곳: 데이터와 다른 디스크 또는 NAS 경로 (프로그램이 매일 자동으로 DB 사본과 파일을 복사합니다) | |
| 서비스 등록 방식: Windows 작업 스케줄러(SYSTEM 계정, 부팅 시 시작) 또는 Linux systemd를 써도 되나요? | |

설치본에는 실행에 필요한 Node.js와 OCR 엔진·모델이 함께 들어 있어 별도 프로그램 설치나 인터넷 연결이 필요 없습니다.

## 2. 직원 PC와 자료

| 확인할 내용 | 답변 |
|---|---|
| 직원 PC 웹 브라우저 종류와 버전 (최신 Chrome 또는 Edge 필요) | |
| 인사 명단 파일 형식 (xlsx / csv)과 들어 있는 열 (사번, 성명, 부서, 직급, 생년월일 등) | |
| 개인정보 처리 시스템으로서 보안성 검토가 필요한가요? 필요하다면 절차와 제출 자료 | |

## 3. 이 시스템의 보안 관련 사항

- 외부 인터넷에 접속하지 않습니다. 화면·글꼴·OCR 모델 등 모든 파일을 서버에서 직접 제공하고, 이수증을 AI 서버나 기관 밖으로 보내지 않습니다.
- HTTPS: 인증서 파일을 지정하면 서버가 직접 HTTPS로 동작하고(쿠키 Secure·HSTS 적용), 리버스 프록시 뒤에서도 운영할 수 있습니다.
- 서무는 담당 부서의 직원과 이수증만 볼 수 있습니다 (서버에서 매 요청 권한을 확인).
- 로그인 5회 실패 시 10분 잠금, 60분 동안 사용하지 않으면 자동 로그아웃됩니다.
- 비밀번호는 복원할 수 없는 방식(scrypt)으로 저장합니다.
- 감사 로그(계정·권한 변경 포함, 3년 이상)와 접속기록(조회·내려받기 포함, 2년 이상)을 남기고, 위·변조 여부를 확인할 수 있게 해시로 이어 저장합니다. 관리자 화면에서 월 1회 접속기록 점검을 기록합니다.
- 개인정보가 든 자료(엑셀·ZIP·PDF)를 내려받을 때 사유를 받아 기록합니다.
- 주민등록번호는 저장하지 않습니다 (명단에 있어도 생년월일만 저장하고, 이수증 글자에 있으면 뒷자리를 가려 저장).
- 보관기간이 지난 자료는 관리자가 확인 후 파기하고, 파기 내역을 남깁니다.
- 매일 자동 백업(무결성 검사 포함)과 복원 연습 도구를 제공합니다.
