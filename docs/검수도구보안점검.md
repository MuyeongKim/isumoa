# 0.5.8 검수 규칙·로컬 AI 변경 점검

이 점검은 추가 기능과 기존 인증·권한·확정 차단 경계에 대한 코드 검토·자동회귀·가상 자료 UI 검증입니다. 악성코드 부재 인증이나 전체 침투시험을 뜻하지 않습니다.

| 경계 | 구현·검증 |
|---|---|
| 외부 규칙 | 공개 저장소의 고정 HTTPS 경로만 조회. 직원 자료 전송 없음. 최대 2MB, SHA-256·Ed25519 서명·호환 버전 검사. 사용자 JSON은 실행 없는 엄격한 선언 형식이며 정규식·명령·알 수 없는 키 거부 |
| 사용자 편집 | 관리자만 편집·적용·복원. 변경 미리보기·동시 수정 토큰·작업 중 교체 차단. 공식·사용자 규칙 분리, 최근 10개 복원, 기존 확정·교육 의무시간 무변경 |
| 로컬 모델 | 기본 꺼짐. 명시적 버튼 요청만 생성. HTTP 루프백만 허용, 환경 프록시·리디렉션 사용 안 함. 로컬 GGUF·blob·생성 지원을 확인하고 클라우드·원격 별칭·임베딩 전용 모델 거부. 모델 설치·다운로드 API 없음 |
| 문서·출력 | 문서를 지시가 아닌 자료로 취급. 알려진 식별정보·번호·연락처 가림, 최대 원문 18,000자. 원본·명단 전체 미전송. 엄격한 응답 형식·원문 근거·날짜·명시 시간·대상 교육·필수 주제 충돌 검사. AI 자체의 의미 오류는 완전히 차단할 수 없어 담당자 대조 필요 |
| 권한·기록 | 기존 자료 열람 범위 검사, 확정·제외 자료 추가 검토 차단. 제안은 편집값에 선택 반영, 자동 저장·확정 없음. 늦은 응답·자료/규칙 변경 거부. 감사 로그는 종류·모델·버전·해시·개수만 기록 |
| 보관·배포 | 규칙·검토 이력은 DB 백업 포함, 분리 위치 실제 복원으로 대조. 설치판에 공개 검증키만 포함. 개인 서명키·운영 DB·원본·계정 제외. 알려진 배포 의존성 취약점과 소스 비밀값 검사 수행 |

수정한 재현 문제: OCR 경로에서 추가 항목 이름 누락, 검토 이력 조회의 SQLite OFFSET 단독 사용 오류, 형식이 비정상인 13자리 식별번호 가림 누락, 업데이트 준비 완료 표시가 파일 닫기보다 빨랐던 경합. 회귀 또는 실제 UI 재검증으로 확인했습니다.

잔여 범위: 가림 처리는 완전한 익명화를 보장하지 않습니다. 같은 PC라도 사용자가 운영하는 로컬 서버 자체를 악성 서버로 바꾸면 앱이 그 내부 동작을 보증할 수 없습니다. Ollama 클라우드 기능을 끄고 신뢰하는 로컬 모델을 사용하세요. 앱 자체 DB·원본 암호화, EXE 코드 서명, Windows 실제 실행·업데이트·Excel/한셀·Defender는 별도 확인 대상입니다. 모델의 추론 속도·한국어 정확도·환각 비율은 이 검증으로 일반화하지 않습니다.


## 0.5.9 안정화 보완

0.5.8의 콜론 없는 개인정보 표·날짜 구분자 차이 누락을 재현해 수정했습니다. 문서 판독값이 없어도 개인정보 항목과 연속 값을 가리며, 허용 범위의 선택한 직원 정보도 치환에 사용합니다. 판독값·원문·관련 교육/규칙 문자열까지 요청 전체를 검사합니다. 교육과 개인정보 머리글의 다음 행 대응이 불명확하면 모델 호출 전에 추가 검토를 보류합니다. 기본 규칙 검수는 유지합니다.

AI 응답은 외곽 형식·개수 상한과 개별 제안을 나눠 검사합니다. 길이·형식 초과 항목만 제외하고 정상 제안은 유지하며, 기관·증서번호 100자 등 실제 저장 한도와 맞춥니다. 없는 근거·주제 충돌·중복 차단은 유지합니다. 전체 응답 오류의 개발용 스키마 메시지를 한국어 안내로 바꾸고 규칙 복원 응답의 version을 보완했습니다.

가림은 알려지지 않은 자유 문장 속 식별정보까지 완전하게 익명화하는 보증이 아닙니다. 신뢰하는 로컬 모델만 사용하고 원본을 직접 대조해야 합니다. 최신 자동검증·UI·설치본 점검 결과는 0.5.9 릴리스 검증 보고서를 기준으로 확인하세요.
