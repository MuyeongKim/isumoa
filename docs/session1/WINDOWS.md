## 현재 0.5.12 배포판 확인표

실제 결과는 아직 입력하지 않았습니다. 기관에서 허용한 별도 시험 PC·가상 Windows·새 Windows 사용자 계정에서 공개 모의자료로 확인하세요. 기존 업무 자료와 백업은 먼저 보관하고 시험 자료를 운영 자료에 섞지 않습니다.

## 과거 0.5.6 분리 검증 절차 (참고)

아래 내용은 당시 별도 제공한 `Windows-분리검증.ps1`을 전제로 한 절차입니다. 해당 도구가 현재 0.5.12 배포 파일에 포함된다는 뜻은 아닙니다. 현재 배포판의 결과는 위 확인표에 기록합니다.

사용자가 0.5.6 EXE를 받아 직접 확인할 항목입니다. macOS의 자동 검사와 EXE 추출 검증은 아래 항목의 통과를 대신하지 않습니다. 기존 업무 자료는 먼저 백업하고 최초 검증에는 모의 자료를 사용합니다.

## 분리된 시험 환경

1. EXE의 SHA-256을 배포 체크섬과 비교하고 기관 정책에 따라 설치합니다. 코드 서명은 없습니다. 보안 프로그램을 끄거나 경고를 우회하지 않습니다.
2. 함께 제공한 `Windows-분리검증.ps1`을 PowerShell의 `-File`로 실행합니다. 정책이 막으면 정보화 담당자에게 확인하며 실행 정책을 우회하지 않습니다.
3. 이 도구는 `%LOCALAPPDATA%\isumoa-session1-qa` 아래 새 자료·백업 폴더와 PC 내부 전용 포트 47925를 사용합니다. 일반 바탕화면 아이콘의 기존 업무 자료와 분리합니다. 포트가 이미 사용 중이면 중단하며 다른 프로세스를 종료하지 않습니다.
4. 처음 실행 화면에서 가상 기관명과 시험용 계정을 직접 정합니다. 실제 직원 명단이나 기존 운영 백업은 이 환경으로 가져오지 않습니다.

업데이트 시험은 별도 시험 PC 또는 기관에서 허용한 가상 Windows에서 수행하세요. 업무용 설치본을 낮은 버전으로 되돌리지 않습니다. 백업 복원은 primary 시험 화면에서 백업을 만든 뒤 해당 창을 종료하고 `powershell -NoProfile -File .\Windows-분리검증.ps1 -Mode Restore`로 수행합니다. restored라는 별도 폴더·47926 포트에 복원하며 기존 복원 DB가 있으면 덮어쓰지 않습니다. 원본 업무 폴더는 대상으로 삼지 않습니다.

## 알려줄 결과

Windows 버전·빌드, Excel 또는 한셀의 제품·버전, 0.5.6 표시, 위 항목의 성공/실패/미실시와 오류 문구만 기록합니다. 계정·PC 사용자명·수료증 원본·개인 경로는 보내지 않습니다. 스크립트가 수집하는 정보도 OS 빌드·아키텍처·앱 버전으로 한정하며 수동 확인 항목을 자동 통과 처리하지 않습니다.
