# 우리 부서 직원 독립 사용 비교

대상은 개발자 도움 없이 사용해볼 우리 부서 직원 2~3명입니다. 이름 대신 P1·P2·P3를 사용합니다. 다른 부서 참여와 실제 업무 도입을 수행한 것으로 기록하지 않습니다.

## 같은 작업을 비교하기

모의 A·B 자료는 각각 수료증 16건, 중복 1건, 관리 대상 밖 교육 1건, 비수료 문서 1쪽입니다. 수료증 16건은 한 가상 직원의 기본 교육 16개를 모두 채웁니다. A·B는 이름·날짜·번호만 바꿔 작업량을 맞춥니다. 실제 직원 개인정보는 사용하지 않습니다.

- P1: A를 Excel로 수기 검토한 뒤 B를 이수모아로 처리합니다.
- P2: A를 이수모아로 처리한 뒤 B를 Excel로 수기 검토합니다.
- P3: 가능하면 B를 Excel로 검토한 뒤 A를 이수모아로 처리합니다.
- 첫 5분은 안내서 읽기·기능 연습에 사용하고 별도 기록합니다. 본 과제에서는 개발자가 방법을 알려주지 않습니다. 도움을 요청하면 횟수와 내용을 기록합니다.

수기 검토는 `직원실측기록.xlsx`의 수기검토 표에 직원·교육·날짜·시간·인정/제외를 입력하고 교육별 합계를 만듭니다. 이수모아는 분리된 시험용 자료 폴더에서 명단 등록 → 기준 확인 → 업로드 → 검수 → 현황 → 엑셀·증빙 내려받기를 수행합니다.

## 완료 조건과 시간

자료를 처음 연 순간부터 수료증 16건 인정, 중복 1건 제외, 대상 밖 1건 제외, 비수료 문서 1쪽 제외, 교육별 합계와 결과 파일 열기까지의 전체 시간을 측정합니다. OCR 대기·오류 수정·도움·다운로드 시간을 포함합니다. 빠진 자료를 끝내지 못하면 미완료로 기록하고 시간 절감 계산에서 제외합니다.

정답표는 진행자가 따로 보관합니다. 참가자가 수료증을 읽는 동안 정답표를 보여주지 않습니다. 종료 후 잘못된 교육 인정, 중복 인정, 미인정 정상 수료증을 별도로 세고 수정 완료까지 걸린 시간을 포함합니다. 속도만 빠르고 오인정이 늘어난 결과를 개선으로 결론 내리지 않습니다.

## 기록과 해석

실측기록의 노란 칸에 초 단위 시간, 잘못된 교육 연결 수, 중복 인정 수, 도움 횟수, 완료 여부, 파일 열기 결과를 입력합니다. 공란은 미측정입니다. 0은 실제 확인한 0건일 때만 씁니다. 참가자의 소감은 관찰 사실과 구분해 적습니다.

동일 직원의 두 방법이 모두 완료된 경우만 감소 시간과 비율을 계산합니다. 표본 2~3명의 탐색적 부서 시범 결과이며 전체 기관·다른 부서로 일반화하지 않습니다. AI가 대신 누른 CUA 검증 시간은 직원 실측 시간에 섞지 않습니다.
