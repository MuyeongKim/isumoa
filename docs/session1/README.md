# 이수모아 세션1 제출 준비

법정교육 수료증에서 글자를 읽고 직원·교육·날짜·시간을 검수한 뒤 기관보고 엑셀과 증빙을 만드는 Windows PC 프로그램입니다. AI-OCR, 규칙 검사, 담당자의 원본 대조를 연결합니다.

## 현재 배포본과 실행 안내

현재 Windows 배포본은 **0.5.13**입니다. 공공 GitLab 릴리스에서 설치 EXE와 `isumoa-session1-sample-data.zip`을 받으면 가상 직원 120명과 PDF 11개·50쪽으로 시연을 재현할 수 있습니다. 설치 방법, LLM 연결, 자료 구성, 사용 순서는 프로젝트 README에 있습니다. [공공 GitLab v0.5.13 릴리스](https://gitlab.aigov.go.kr/tenmoo/isumoa/-/releases/v0.5.13) · [프로젝트 README](../../README.md)

구동안내서 PDF는 원문 양식 2-1의 실행 환경 → 설치·실행 절차 → LLM 연결 설정 → 모의데이터 안내 → 기능 사용 순서 → 알려진 제약 사항 → 개발 경위 요약 순서를 따릅니다.

## 준비 범위

| 항목 | 결과와 구분 |
|---|---|
| 검수 화면 | 원본 전체 보기·확대, 선택한 인정 교육과 시간, 확정·제외를 함께 표시. 교육 변경은 검색 가능한 선택 창 |
| Windows·Excel | Windows PC에서 0.5.13 설치·첫 실행, 모의자료 검수와 16시트 명단 내보내기를 확인. Microsoft Excel에서 복구 안내 없이 열림. [Windows 확인 결과](WINDOWS.md) |
| 판독 | 새 합성 문서의 최초 측정·보완·회귀 결과와 보완 후 별도 합성 서식 평가를 구분. 실제 신규 발급기관 정확도로 일반화하지 않음 |
| 직원 사용 | 우리 부서 직원의 독립 사용과 Excel 수기 검토 비교를 위한 [실측 절차](PILOT.md). 개발자 도움과 수정시간 포함 |
| 타 부서 | 모의 부서의 자료·교육 기준 변경으로 기술 재사용 검증. 실제 다른 부서 직원 사용은 미실시 |
| AI·개인정보 | [AI 및 자료 처리](AI-DATA.md). 수료증을 외부 모델에 전송하거나 모델에 재학습시키지 않음 |
| 제출물 | 참가신청서(1-1), 구동안내서(2-1), Windows에서 촬영한 2분 15초 시연영상, 모의자료, 공공 GitLab 소스와 설치 파일 |

## 제출본을 고정하는 순서

1. 제출 문서와 시연영상의 버전이 설치 파일과 같은지 확인하고, 시험에서 확인한 범위를 기록합니다.
2. 공공 GitLab 비공개 프로젝트의 소스와 README를 확인하고 릴리스에서 설치 EXE와 모의자료가 내려받아지는지 확인합니다. [이수모아 공공 GitLab 프로젝트](https://gitlab.aigov.go.kr/tenmoo/isumoa) · [0.5.13 설치 릴리스](https://gitlab.aigov.go.kr/tenmoo/isumoa/-/releases/v0.5.13)
3. 프로젝트에 세션 1 지정 Topic `2026_challenge_session_1`을 붙이고 참가신청서에 프로젝트 주소를 적습니다.
4. 참가신청서의 동의·서명을 마친 뒤 구동안내서 PDF와 시연영상 MP4를 함께 이메일로 제출합니다. 모의자료는 선택 첨부입니다. 기관의 참가자 목록 공문은 별도로 접수합니다.
5. 제출할 커밋과 파일의 SHA-256을 기록하고 마감 후 제출 저장소를 변경하지 않습니다. 이후 일반 제품 개발은 원래 저장소에서 진행합니다.

세션 1·2 제출 양식과 파일 규격은 참가 안내에서 확인할 수 있습니다. [행정안전부 참가 안내](https://www.mois.go.kr/frt/bbs/type013/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000006&nttId=130237)
