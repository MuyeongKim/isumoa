# 이수모아 세션1 제출 준비

법정교육 수료증에서 글자를 읽고 직원·교육·날짜·시간을 검수한 뒤 기관보고 엑셀과 증빙을 만드는 Windows PC 프로그램입니다. AI-OCR, 규칙 검사, 담당자의 원본 대조를 연결합니다.

## 준비 범위

| 항목 | 결과와 구분 |
|---|---|
| 검수 화면 | 원본 전체 보기·확대, 선택한 인정 교육과 시간, 확정·제외를 함께 표시. 교육 변경은 검색 가능한 선택 창 |
| Windows·Excel | 배포판을 받은 사용자가 실기기에서 확인. 절차는 [Windows 검증](WINDOWS.md), 결과는 아직 미입력 |
| 판독 | 새 합성 문서의 최초 측정·보완·회귀 결과와 보완 후 별도 합성 서식 평가를 구분. 실제 신규 발급기관 정확도로 일반화하지 않음 |
| 직원 사용 | 우리 부서 직원의 독립 사용과 Excel 수기 검토 비교를 위한 [실측 절차](PILOT.md). 개발자 도움과 수정시간 포함 |
| 타 부서 | 모의 부서의 자료·교육 기준 변경으로 기술 재사용 검증. 실제 다른 부서 직원 사용은 미실시 |
| AI·개인정보 | [AI 및 자료 처리](AI-DATA.md). 수료증을 외부 모델에 전송하거나 모델에 재학습시키지 않음 |
| 제출물 | 구동안내서·실제 UI 장면을 담은 영상·모의 자료·소스 고정본 초안. 기관·팀 정보, 동의·서명, 제출은 사용자 확인 필요 |

## 제출본을 고정하는 순서

1. Windows 및 우리 부서 직원 실측 결과를 반영하고 확인하지 못한 항목은 그대로 표시합니다.
2. 공공 GitLab의 비공개 제출 전용 프로젝트에 소스·실행물·실행 방법·구동안내서·시연영상·모의 자료를 등록합니다. 일반 사용자 배포 EXE는 계속 GitHub Releases에서 제공합니다.
3. 주제는 `2026 공공 AI 대전환 챌린지 세션1`로 설정하고 신청서에 프로젝트 주소를 기재합니다.
4. 기관·팀 정보와 동의·서명은 사용자가 작성합니다. 메일 제출과 기관 공문 접수는 프로그램 배포와 별도입니다.
5. 제출할 커밋과 파일의 SHA-256을 기록하고 마감 후 제출 저장소를 변경하지 않습니다. 이후 일반 제품 개발은 원래 저장소에서 진행합니다.

규격 근거는 [행정안전부 참가 안내](https://www.mois.go.kr/frt/bbs/type013/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000006&nttId=130237)의 세션1·2 제출 안내입니다. 현재 준비본은 최종 참가신청이나 기관 도입 실적을 뜻하지 않습니다.
