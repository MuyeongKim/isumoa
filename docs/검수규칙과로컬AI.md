# 검수 규칙과 선택형 로컬 AI

0.5.8 이상에서 사용합니다. 이전 설치판은 EXE를 한 번 업데이트한 뒤, 지원하는 교과명·검색어·발급기관·연도·인식 항목 이름은 규칙 파일만 갱신할 수 있습니다. OCR 엔진·화면·보안 로직 변경은 프로그램 업데이트가 필요합니다.

## 사용자 규칙을 쉽게 만들기

1. 설정 → 검수 규칙 → 사용자 규칙 추가를 누릅니다.
2. 규칙 이름과 연결할 교육을 선택하고 정확한 과정명 또는 포함 검색어를 한 줄에 하나씩 입력합니다. 발급기관·연도·제외어로 범위를 좁히세요. ‘정보’, ‘교육’ 같은 공통 단어만으로 연결하지 않습니다.
3. 참고 시간은 문서와의 차이 안내에만 씁니다. 수료증 시간·연간 의무시간은 덮어쓰지 않습니다.
4. 변경 미리보기에서 추가·변경·삭제를 확인하고 적용합니다.
5. 규칙.json 내보내기로 다른 PC에 전달합니다. 규칙.md는 설명용이며 실행하지 않습니다.

다른 PC에서는 규칙 JSON 가져오기를 사용합니다. 기본은 기존 사용자 규칙에 추가·갱신이며, 같은 규칙 ID는 갱신됩니다. 전체 교체는 별도로 선택해야 합니다. 이 PC에 없는 교육 코드는 화면에서 해당 교육을 골라 연결합니다. 사용자 편집은 공식 규칙과 별도로 보관합니다. 공식 통일교육의 검증된 과정 연결이나 필수 주제 충돌·중복 차단을 사용자 규칙으로 해제할 수 없습니다.

‘인식 항목 이름 편집’에서는 ‘학습주제 → 과정명’, ‘수강완료일 → 이수일’처럼 항목 이름을 추가합니다. 기본 항목을 다른 의미로 바꾸는 충돌은 거부합니다. JSON은 최대 2MB이고 스키마·교육 코드·지원 버전을 검사합니다. 정규식·스크립트·실행 명령은 지원하지 않습니다. 예제는 [사용자 규칙 JSON](examples/규칙.json)입니다.

## 공식 규칙 업데이트·복원

‘최신 공식 규칙 확인’은 공개 배포 저장소의 고정 주소에서 JSON을 받으며 업무 자료를 보내지 않습니다. SHA-256·Ed25519 서명과 앱 호환 버전을 검사하고 적용 전 변경을 보여줍니다. 인터넷이 없는 PC는 공식 JSON 파일을 옮겨 가져올 수 있습니다. 개인이 편집한 파일은 사용자 규칙으로 가져오세요. 공식 서명·배포 개인키는 설치판에 포함하지 않습니다.

적용 이력에서 최근 10개 설정으로 복원할 수 있습니다. 수료증 판독 작업이 진행 중이면 적용·복원을 보류합니다. 규칙은 DB 백업에 함께 보관됩니다. 새 업로드부터 적용하고 기존 대기 자료는 검수함 → 추가 검토 → 규칙 다시 검토로 후보만 비교합니다. 기존 확정·제외·직접 수정값은 자동으로 변경하지 않습니다.

## 선택형 로컬 AI

기본은 꺼짐입니다. LLM이 없는 PC는 아무 설정도 하지 않아도 됩니다. 모델 다운로드·설치·구동은 사용자가 관리하며 이수모아 설치판은 모델을 포함하지 않습니다.

1. 같은 PC에서 Ollama와 신뢰하는 생성 모델을 준비합니다.
2. 설정 → 로컬 AI(선택)에서 로컬 주소(기본 http://127.0.0.1:11434)의 연결 테스트·모델 목록을 누릅니다.
3. 설치된 로컬 생성 모델을 선택하고 사용을 켠 뒤 저장합니다. GGUF·로컬 blob·생성 지원 여부를 다시 검사합니다. 클라우드·원격 별칭·임베딩 전용 모델과 외부·내부망 주소는 거부합니다. HTTP 리디렉션·환경 프록시를 사용하지 않습니다. Ollama 자체의 클라우드 기능도 꺼 두는 것을 권장합니다.
4. 검수 대기 수료증에서 추가 검토 → AI 추가 검토를 누릅니다. 업로드할 때 자동 호출하지 않습니다.
5. 현재 값·제안·근거 문구를 대조하고 반영할 항목만 체크합니다. ‘편집값에 반영’ 후에도 임시 저장·확정은 별도로 해야 합니다.

판독값과 개인정보를 가린 원문 일부만 이 PC의 모델에 전달합니다. 알려진 성명·생년월일·소속, 식별번호·연락처·이메일을 가리지만 완전한 익명화를 보장하지 않습니다. 직원 전체 명단·원본 PDF·사진을 모델로 전송하지 않습니다. 이미지 이해 기능은 포함하지 않으며 OCR이 틀리면 AI도 틀릴 수 있습니다.

근거가 원문에 없는 제안·허용하지 않는 교육 코드·차시를 임의로 시간으로 바꾼 제안·주제 충돌 후보는 걸러냅니다. 그래도 AI가 옳다는 보장은 없습니다. 의견 없음·연결 실패·응답 시간 초과·잘못된 형식이면 기존 입력을 유지하고 규칙 검수로 계속할 수 있습니다. 입력을 수정하거나 다른 자료로 이동하면 오래된 제안을 취소합니다. 확정·제외 건은 추가 검토로 변경하지 않습니다.

제안과 사용 규칙·모델·입력 해시는 검토 이력으로 보관합니다(수료증·검토 종류별 최근 5개). 전체 프롬프트는 감사 로그에 쓰지 않습니다. 업무 자료·DB·백업은 앱 자체 자동 암호화가 없으므로 PC와 백업 접근 권한을 관리하세요.

## 확인 범위

macOS의 분리 가상 DB와 설치된 로컬 모델로 연결·응답을 확인했습니다. 모델마다 결과·메모리·시간이 다릅니다. 특정 모델 설치를 필수로 요구하지 않습니다. Windows 실제 설치·업데이트·로컬 모델 실행·Excel/한셀과 기관 백신은 별도 실기기 확인이 필요합니다.
