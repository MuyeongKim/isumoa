# 이수모아 0.4.2 — 새 사용자 UI 10회 재검증·배포 결과

2026-10-28 (KST). 기준 버전0.4.1에서 새 가상환경으로 다시 시작했고, 이전10회 검증을 이번 회차로 재사용하지 않았다.

**새 UI 시나리오 10회 완료, UI/사용 흐름 보완12항목과 설치·실행 보완3항목을 반영했다. 0.4.2 EXE를 생성하고 파일·실제 포함 스크립트를 검증했다. Windows 실제 설치·실행은 미검증이며 코드 서명은 없다.**

## 검증 방식

회차마다 별도 DB·관리자·가상 직원2명으로 처음 설정→명단→교육 기준→수료증→검수→현황→실제 다운로드를 수행했다. CUA의 실제 파일 선택·버튼·라디오·체크박스로 조작했고, API로 자료를 넣은 것을 UI 통과로 바꾸지 않았다. 10명의 실제 초보자가 참여한 사용자 시험은 아니다.

지연·통신 실패는 검증 탭에만 주입했고 모두 해제했다. 750px 임시 화면 크기도 기본값으로 돌렸다. 운영 앱의 DB·원본·백업에서 조작 시험을 하지 않았다. 미리보기 화면은 별도 web-dist로 빌드해 기존 실행 화면과 분리했다.

## 최종 자동·배포 검증

- 타입 검사·빌드·git diff --check 통과. 32개 파일, 자동 테스트300개 통과(0.4.2 로그).
- 실제 CUA 검증에 사용한 화면과 배포 화면 561개 파일 해시가 정확히 일치.
- EXE 압축 무결성 검사 통과. 추출한 제품/설치 파일 12,167개 해시와 빌드 원본 일치. 현재 서버·공통 소스·Windows 스크립트 91개도 일치.
- 설치 manifest의 12,165개 파일을 EXE 안의 실제 PowerShell 함수로 검사.
- 최종 EXE에서 추출한 유지보수 스크립트로35개 성공/실패 사례와3개 프로세스 잠금 사례 통과. 실제 제품 HTTP 확인 응답을 사용했으며 확인되지 않은 서버로 실행 열쇠가 전송되지 않음.
- 사용자 DB·원본 수료증·개인 로그인값은 EXE에 포함되지 않음. Windows x64 Node·OCR 라이브러리·한국어 모델 포함 확인.
- R10의 UI 백업 후 별도 restore --check에서 체크섬·DB 무결성·로그 체인·원본·쪽 이미지 보존 확인. 운영 DB를 과거 백업으로 바꾸지 않음.

PowerShell 검증은 Mac의7.6.9에서 가상 폴더와 실제 제품 함수로 수행했다. Windows 전용 복사 수단은 시험에서 대체했고, OS 등록 동작은 콜백/가상 등록으로 시험했다. Windows 10·11의 실제 설치 UI, PowerShell5.1, robocopy/CIM/레지스트리/바로가기, 실제 OCR 전체 기동·업그레이드·제거를 현장에서 확인한 것은 아니다. 전원 차단·OS 강제 종료 복구도 별도 검증 대상이다.
