# 이수모아 사용설명서

> 교육 담당자를 위한 안내입니다. 관리자 한 계정으로 모든 부서를 관리할 수 있습니다. 버전 0.3 기준. 그림 속 기관·사람은 모두 가상입니다.

**이수모아**는 법정교육 이수증을 모으고, 확인하고, 이수 현황을 보고, 제출 양식까지 채우는 일을 한곳에서 합니다. 처음이라면 [처음 시작하기](#1-처음-시작하기)부터 차례로 읽고, 익숙해지면 필요한 부분만 찾아 보세요.

**한 해의 흐름**

1. 연초: 인사 명단으로 직원을 등록하고 교육 과정 기준을 확인합니다.
2. 수시로: 걷은 이수증을 올리고, 검수함에서 확인해 확정합니다.
3. 수시로: 대시보드와 이수 현황에서 남은 사람을 찾아 독려합니다.
4. 제출 때: 현황 엑셀이나 제출 양식에 채운 파일을 받아 냅니다.

---

## 1. 처음 시작하기

### 1-1. 프로그램 열기

- **PC판**: 바탕화면의 **이수모아** 아이콘을 누르면 브라우저에 화면이 열립니다. 설치 방법은 [PC 설치 안내](PC설치안내.md)를 보세요.
- **서버판**: 정보화 담당에게 받은 주소(예: `https://isumoa.기관.go.kr`)를 Edge나 Chrome으로 엽니다.

### 1-2. 처음 설정과 로그인

처음 열면 **기관명**과 **관리자 계정**(교육 담당자)을 만드는 화면이 나옵니다. 그다음부터는 아이디와 비밀번호로 로그인합니다.

![로그인 화면](images/login.webp)

- 비밀번호는 영문 대·소문자·숫자·특수문자 중 2가지 이상이면 10자 이상, 3가지 이상이면 8자 이상이어야 합니다.
- 5번 틀리면 10분 동안 잠깁니다. 관리자가 **설정 > 사용자 계정**에서 비밀번호를 초기화하면 바로 풀립니다.
- 60분 동안 쓰지 않으면 저절로 로그아웃됩니다.

### 1-3. 시작 준비

관리자로 처음 로그인하면 대시보드 위쪽에 **처음 한 번만 준비하세요**가 나옵니다. 직원 명단과 교육 기준을 준비하면 안내가 사라집니다. 부서별 서무 계정은 만들지 않아도 됩니다.

| 순서 | 할 일 | 어디서 |
|---|---|---|
| 1 | 기관 정보 확인 | 설정 > 기관 정보 |
| 2 | 인사 명단으로 직원 등록 | 직원 명단 > 엑셀로 일괄 등록 ([2장](#2-직원-명단-등록)) |
| 3 | 교육 기준 확인 | 교육 기준 > 기준 확인 완료 ([3장](#3-교육-과정과-계정)) |

## 2. 직원 명단 등록

이수율은 **등록된 직원**을 기준으로 계산합니다. 인사 시스템에서 받은 명단 엑셀(.xlsx)이나 CSV를 그대로 올리면 됩니다. 옛 엑셀(.xls)은 엑셀에서 **다른 이름으로 저장**으로 `.xlsx`로 바꿔 올려 주세요.

1. **직원 명단 > 엑셀로 일괄 등록**에서 파일을 고릅니다.
2. **열 확인**: 프로그램이 머리글(사번·성명·소속·직급…)을 찾아 열을 맞춰 둡니다. 다르면 고릅니다.
3. **미리보기**: 새로 등록, 바뀜(부서 이동·승진), 같음, 오류로 나눠 보여 줍니다.
4. **반영**하면 끝납니다.

![직원 명단 일괄 등록 — 열 확인](images/import.webp)

- 주민등록번호 열이 있어도 **생년월일만** 저장하고 나머지 번호는 저장하지 않습니다.
- 사람이 바뀔 때마다 새 명단을 다시 올리면 바뀐 사람만 고칩니다. 명단에서 빠진 사람을 퇴직으로 바꿀지도 고를 수 있습니다.
- 한두 명은 **직원 명단 > 직원 추가**로 직접 넣어도 됩니다.

![직원 명단](images/employees.webp)

관리자는 직원 행 왼쪽의 **체크박스**로 여러 명을 골라 **선택 삭제**할 수 있습니다. 머리글 체크박스는 현재 페이지 전체를 고르고, 검색 결과가 여러 쪽이면 **검색 결과 모두 선택**도 사용할 수 있습니다(한 번에 1,000명까지).

삭제한 직원은 **삭제한 직원 보기 > 선택 복원**으로 되돌립니다. 이수증·기존 기록은 보관하며, 휴지통에 있는 동안 직원 매칭·이수 현황·내보내기에서 제외합니다. 사번이 같은 직원을 다시 만들거나 명단을 반영하기 전에 먼저 복원해 주세요.

**설정 > 부서**에서도 체크박스로 **선택 삭제**합니다. 소속 직원도 함께 휴지통으로 옮기며, 확인 창에 직원 수를 표시합니다. **삭제한 부서 보기 > 선택 복원**을 누르면 함께 삭제한 직원도 복원합니다. 부서보다 먼저 별도로 삭제한 직원은 직원 휴지통에 남습니다. 서무 연결과 제출 양식도 보관하고, 삭제된 부서에 대한 접근은 중단합니다.

## 3. 교육 과정과 계정

### 교육 과정

**교육 기준** 화면에 공공기관 법정교육 기본 목록이 들어 있습니다(성희롱·성매매·성폭력·가정폭력 예방, 청렴, 장애인 인식개선, 개인정보보호 등).

- 교육마다 **이수 기준**(연 n시간 이상 또는 연 n회 이상)과 **찾을 단어**가 있습니다. 이수증의 과정명에 찾을 단어가 있으면 그 교육으로 분류합니다. 예: "공직자 반부패 교육" → 청렴교육(찾을 단어 '반부패').
- 기관 지침과 다르면 고치고, 기관에서 따로 정한 교육은 추가합니다. 쓰지 않는 교육은 끕니다.
- 관리자는 교육 행의 **삭제** 또는 체크박스로 여러 교육을 골라 **선택 삭제**할 수 있습니다. 삭제한 교육은 자동 분류·이수 현황·내보내기에서 제외하며, 연결된 이수증·인정 내역은 보관합니다. **삭제한 교육 보기 > 선택 복원**으로 되돌리면 원래 사용 상태와 기존 연결을 다시 사용합니다. 삭제된 교육이 포함된 검수 대기는 교육을 복원하거나 인정 교육을 다시 고른 뒤 확정합니다.

**교육 기준표 가져오기**(또는 **교육 기준 추가 > 교육 기준표 가져오기**)에서 교육 계획·안내 문서의 **PDF·HWPX**나 **JPG·JPEG·PNG 사진**을 올릴 수 있습니다. 파일은 20MB 이하, PDF는 100쪽 이하, 사진은 4,000만 화소 이하로 올립니다. 교육명·시간·횟수·근거 법령·명시된 적용 연도를 읽어 초안으로 채우고, 사진과 스캔 PDF는 프로그램의 OCR로 읽습니다. 파일은 외부로 전송하지 않습니다.

미리보기에서 원문을 대조하고 값을 고친 뒤 등록할 교육만 체크해 **선택한 교육 등록**을 누릅니다. 같은 이름의 기존 교육은 중복 표시하고 처음에는 선택하지 않습니다. 찾지 못한 이수 기준은 빈칸으로 두므로 직접 입력해야 합니다. 문서 양식·사진·스캔 품질에 따라 누락이나 오독이 있을 수 있습니다. 사진은 글자가 크고 선명하게 보이도록 촬영하고, 분기별·입사 시 교육 같은 조건은 기관의 연간 기준과 메모에 맞게 확인합니다. HWP 파일은 한글에서 HWPX로 저장해 올립니다.

번호가 연속된 표 사진은 글자의 위치를 이용해 **교육주제·검색어·이수기준**을 같은 행으로 읽습니다. 제목 아래의 괄호 설명과 수강신청 기관은 메모로 보관하고, 여러 줄로 된 검색어는 분리해서 보여 주므로 잘못 나뉜 단어를 확인합니다. 작은 글자가 불확실하게 읽힌 경우에도 미리보기에 확인 안내를 표시합니다.

### 서무 계정 (공동 관리할 때만 선택)

한 사람이 관리하면 관리자 계정만 사용하면 됩니다. 기존 계정과 부서별 권한 기능은 보존하며, 공동 관리가 필요할 때만 **설정 > 사용자 계정**에서 부서 서무 계정을 만들고 **담당 부서**를 정합니다. 서무는 담당 부서 직원과 이수증만 보고 내보낼 수 있습니다. 처음 로그인하면 비밀번호를 바꾸게 되어 있습니다.

## 4. 이수증 올리기

나라배움터 수료증의 **과정·기간·상시학습인정시간** 항목과 두 줄 이상으로 이어진 과정명도 읽습니다. 소속 기관과 부서가 따로 적혀 있으면 함께 비교합니다. 기수·연도·모바일 겸용 표기는 확정한 과정명 매핑을 찾을 때 정리하되 원본 과정명은 그대로 보관합니다.

나라배움터 공식 목록에서 확인한 `[2026-1기]` 같은 기수도 매핑할 때 정리합니다. 정보보안→정보공개, 긴급자동차·교통안전→긴급복지처럼 다른 주제를 연결한 기존 확정 매핑은 자동 재사용하지 않습니다. 현재 연결한 교육과 과정명의 주제가 충돌하면 빨간 오류로 표시하며, 관리자도 개별 확정·단축키·일괄 확정으로 넘길 수 없습니다. 대기 상태로 저장하거나 제외할 수 있고, 인정할 교육 또는 잘못 읽힌 과정명을 바로잡아 충돌이 해소되면 확정할 수 있습니다. 과정명을 비우면 원본에서 읽은 과정명으로 충돌을 확인합니다. 통합과정의 인정 범위는 사람이 확인합니다. 공식 목록의 과정별 인정시간으로 기관의 연간 의무 기준을 바꾸지 않습니다. 참고한 범위는 2026-10-27에 확인한 [국가공무원인재개발원 나라배움터 중앙 목록](https://e-learning.nhi.go.kr/crs/apply/elrnAllApplyListByCl.do)이며, 기관별 전체 목록을 전수 확인한 것은 아닙니다.

키워드나 기존 확정 매핑이 맞지 않아 교육과정 이름만으로 후보를 채운 경우에는 **인정 범위 확인** 경고를 표시하고 일괄 확정에서 제외합니다. 수료증의 교육시간은 원본대로 유지하므로, 예를 들어 4시간 수료증을 확정해도 5시간 기준은 부분이수로 표시합니다.

수료증 판독과 **현재 관리 대상 교육에 해당하는지**는 따로 판단합니다. ‘긴급·안전·교육’ 같은 공통 단어만으로 자동 선택하지 않으므로 긴급자동차 교육을 긴급복지 교육으로 연결하지 않습니다. 관리 목록과 연결되지 않은 수료증은 확인 대상으로 남고, 대상 밖이면 **제외 > 관리 대상 교육이 아님**을 선택합니다. ‘보고듣고말하기’처럼 다른 표기로 된 강좌는 관련 교육 후보를 보여 주되 인정 범위를 확인하도록 표시합니다.

PDF가 다시 발급되어 파일 바이트가 달라도 **동일 직원·발급기관·증서번호**를 비교해 중복 후보를 찾습니다. 기존의 직원·교육·이수일 중복 검사도 함께 사용합니다. 중복 후보는 일괄 확정에서 제외하며, 제외한 원본과 기록은 보관합니다.

직원·기관·증서번호뿐 아니라 이수일과 과정명까지 같은 증서가 이미 확정돼 있으면 재발급본의 추가 확정을 차단합니다. 날짜나 과정명이 다른 번호 중복은 확인 후보로 표시해 별도로 대조합니다.

PDF의 내부 글자 저장 순서가 화면 배치와 달라도 글자의 위치를 기준으로 읽습니다. 수료증을 **교육 기준 > 교육 기준표 가져오기**에 올린 경우에는 과정명과 실제 수료시간을 참고용으로 표시하고, 연간 의무 기준은 직접 확인해 입력하도록 빈칸으로 둡니다.

![이수증 올리기](images/upload.webp)

1. **대상 연도**를 고르고, 필요하면 **메모**(예: "상반기 폭력예방교육 제출분")를 적습니다.
2. 이수증 파일을 끌어다 놓거나 눌러서 고릅니다. 화면 어디로 끌어와도 받습니다.
   - PDF, JPG, PNG를 여러 개 한 번에 올릴 수 있습니다.
   - 여러 장을 한꺼번에 스캔한 PDF는 **쪽마다 나눠서** 한 장씩 읽습니다.
3. 올린 쪽은 차례로 읽고, **다 읽은 것부터 검수함에 들어갑니다.** 다른 화면으로 가도 계속 처리합니다.

알아 두면 좋은 것:

- 같은 파일을 다시 올리면 "이미 올린 파일"로 건너뜁니다.
- 글자가 든 PDF는 글자를 그대로 읽고, 스캔본·사진은 프로그램 안의 OCR로 읽습니다. **이수증은 인터넷이나 AI로 보내지 않습니다.**
- 이수일이 대상 연도와 다르면 검수할 때 확인 표시가 붙습니다.
- **올린 묶음** 목록에서 그 묶음만 검수하거나, 다시 읽거나, 이어서 더 올릴 수 있습니다.

## 5. 검수하기

검수함에서 원본과 읽은 값을 대조하고 **확정**합니다. 확정해야 이수 현황에 들어갑니다.

![검수함](images/review.webp)

화면은 세 부분입니다: 왼쪽 **이수증 목록**, 가운데 **원본**, 오른쪽 **읽은 값**.

1. 목록에서 이수증을 고릅니다. 이름 옆 점의 색이 상태입니다.
2. 오른쪽 위의 표시를 봅니다.

   | 색 | 뜻 | 할 일 |
   |---|---|---|
   | 빨강 | 고칠 점 (직원을 못 찾음, 교육을 못 정함 등) | 직원이나 교육을 골라야 확정할 수 있습니다 |
   | 주황 | 확인할 점 (연도가 다름, 이수증이 아닌 쪽 같음 등) | 원본을 보고 맞으면 확정, 아니면 제외 |
   | 파랑 | 안내 (스캔본은 이름·날짜를 원본과 대조하세요) | 한 번 대조합니다 |

3. **직원**: 명단에서 찾은 사람이 맞는지 봅니다. 다르면 이름이나 사번으로 찾아 고릅니다.
4. **인정할 교육**: 통합과정 이수증이면 여러 교육을 고릅니다. 교육시간을 나눠 인정합니다.
5. **이수일·교육시간·인정 연도**를 확인하고 **확정**합니다. 이수증이 아니면(표지, 빈 쪽) **제외**합니다.

| 단축키 | 하는 일 |
|---|---|
| `↑` `↓` (또는 `K` `J`) | 이전·다음 이수증 |
| `Ctrl` + `Enter` | 확정 |
| `X` | 제외 |

- 고칠 점·확인할 점이 하나도 없는 이수증은 **정상 n건 일괄 확정**으로 한 번에 확정할 수 있습니다.
- 확정한 뒤에도 **확정** 탭에서 고르고 **검수 대기로 되돌리기**로 다시 고칠 수 있습니다.
- 원본은 **화면 맞춤 / 크게 보기**, 90° 돌리기, **읽은 글자** 보기를 할 수 있습니다.

### 검색과 선택 제외

검색창에 **직원명·사번·교육 항목명·원본 과정명·파일명**을 입력하고 **검색** 또는 Enter를 누릅니다. 띄어 쓴 검색어는 모두 포함하는 자료를 찾습니다. 예: `홍길동 청렴`, `report (25)`. 한글 자모 분리와 영문 대소문자는 정리해서 비교합니다.

검색은 현재 **묶음·검수 상태·확인할 점** 범위에 적용합니다. 검색 결과 건수를 따로 보여 주며, 검색어·묶음·상태·필터를 바꾸면 체크 선택은 초기화합니다. 수정 중 검색으로 다른 자료로 이동할 때도 미저장 입력 보호가 작동합니다.

1. **검수 대기** 또는 **확정** 탭에서 행 왼쪽 체크박스로 고릅니다. **현재 검색 결과 전체 선택**은 보이는 검색 결과만 고르며, 한 번에 500건까지 선택합니다. 다시 읽는 중인 수료증은 판독이 끝나야 선택할 수 있습니다.
2. **선택 n건 제외**에서 대상 파일·직원·과정과 대기/확정 건수를 확인합니다. 미저장 수정값이 있으면 먼저 임시 저장합니다.
3. 사유를 직접 고른 뒤 **n건 제외**를 누릅니다. 확정 자료가 포함되면 해당 건이 이수 현황 합산에서 빠진다는 안내를 보여 줍니다.
4. 제외된 자료는 **제외** 탭에서 검색할 수 있고, **검수 대기로 되돌리기**로 다시 검수할 수 있습니다. 원본·인정 교육 연결·기존 확정 정보는 보존하며 선택하지 않은 기록은 바꾸지 않습니다.

확인창을 연 뒤 선택한 자료가 수정·확정·제외되거나 다시 읽기 상태가 되면 전체 작업을 중단합니다. 목록을 다시 확인하고 새로 선택해 주세요. 제외 사유와 각 대상·이전 상태는 감사 로그에 남습니다. **정상 n건 일괄 확정**도 현재 검색 결과 안에서만 처리합니다.

### 수정값 보존과 완료 안내

- **임시 저장**은 검수 대기로 저장하며 현황에는 반영하지 않습니다. **저장하고 다음**은 저장 뒤 다음 수료증으로 이동합니다.
- 수정한 채 다른 수료증·묶음·탭·메뉴로 이동하거나 로그아웃하면 **계속 수정 / 버리고 이동 / 저장 후 이동**을 고릅니다. 저장에 실패하면 이동하지 않고 입력값과 오류를 유지합니다. 새로고침·창 닫기는 브라우저가 미저장 경고를 보여 줍니다.
- 저장·확정 실패 시 오류 위치로 이동하며, 하단 버튼 옆에도 실패 안내를 보여 줍니다. 고칠 점이 남아 있으면 서버가 확정을 차단합니다.
- 제외할 때는 대상 파일을 보고 사유를 직접 고릅니다. 미저장 수정값이 있으면 기본적으로 임시 저장한 뒤 제외합니다. 저장할 수 없는 입력을 버리려면 해당 선택을 해제하고 기존 기록으로 제외할 수 있습니다.
- 제외 완료 자료의 과거 확인점은 **이전 검수 내용 보기**에 보관하며 현황에 합산하지 않는 상태를 먼저 보여 줍니다.
- 대기와 읽기가 없으면 **검수가 끝났습니다**와 확정·제외 건수, **이수 현황 보기 / 내보내기**를 보여 줍니다. 읽기 실패나 필터 때문에 빈 목록은 별도로 안내합니다.

### 검수 대기 초기화

상단의 보조 버튼 **검수 대기 초기화**를 누르면 현재 고른 묶음(또는 모든 묶음)의 대기 결과와 미완료 읽기 쪽 수를 먼저 보여 줍니다. **대기만 초기화**를 누르면 대기 중 입력한 수정값과 판독 결과, 대기·진행·오류 읽기 작업을 비웁니다. 확정·제외 기록, 원본 파일·쪽 이미지, 직원·교육과정, 확정하면서 기억한 과정 연결은 유지합니다. 서무는 자신이 올린 묶음만 초기화할 수 있습니다.

비울 대기·읽기·오류 작업이 없으면 초기화 버튼은 비활성화됩니다. 진행 중이던 읽기 결과는 초기화 뒤에 다시 나타나지 않습니다. 확인창을 연 뒤 다른 사람이 자료를 수정·확정하면 변경된 범위를 다시 확인해야 합니다. **올린 묶음 > 다시 읽기**로 원본의 판독 결과를 다시 만들 수 있으나 초기화 전 직접 입력했던 수정값은 다시 작성해야 합니다. 확정·제외된 쪽은 다시 읽기에서도 보존합니다.

## 6. 현황 보기

### 대시보드

![대시보드와 직원 지도](images/dashboard.webp)

- **전체 이수율**: 직원 × 교육 칸 가운데 이수한 비율입니다. 확정한 이수증만 셉니다.
- 오른쪽 숫자(모든 교육 이수, 남은 교육이 있는 직원, 검수 대기, 읽는 중)를 누르면 그 화면으로 갑니다.
- **직원 지도**: 한 칸이 직원 한 명입니다. 마우스를 올리면 남은 교육이 보이고, 누르면 그 사람의 이수 현황으로 갑니다.

| 칸 모양 | 뜻 |
|---|---|
| 꽉 찬 초록 | 모든 교육 이수 |
| 반쯤 찬 주황 | 일부 이수 (시간이 모자라거나 아직 안 들은 교육이 있음) |
| 빨간 테두리 | 아직 이수한 교육이 없음 |
| 가는 회색 줄 | 모든 교육이 대상 제외 (휴직·파견 등) |

### 이수 현황

![이수 현황](images/status.webp)

- 직원 × 교육 표입니다. 위쪽에 교육별 이수율, 아래에 직원별 칸이 있습니다.
- **이름·초성·사번으로 찾기**: `김민준`, `ㄱㅁㅈ`, `2014` 모두 됩니다.
- **미이수·부분이수가 있는 직원만**을 켜면 독려할 사람만 남습니다.
- 칸을 누르면 그 판정의 근거가 된 이수증을 볼 수 있습니다.
- 휴직·파견 중이거나 그 교육의 대상이 아닌 직원은 **대상 제외**로 표시하고 이수율 계산에서 뺍니다.

### 빠른 이동 (`Ctrl` + `K`)

![빠른 이동](images/palette.webp)

어느 화면에서든 `Ctrl` + `K`를 누르면 빠른 이동 창이 열립니다. 메뉴 이름이나 **직원 이름**을 입력하고 `Enter`를 누르면 바로 갑니다. 이름은 초성(`ㄱㅁㅈ`)으로도 찾고, 직원을 고르면 그 사람의 이수 현황으로 갑니다.

## 7. 내보내기

![내보내기](images/export.webp)

**내보내기**에서 먼저 **받을 자료**(현황 엑셀·개인별 합본 PDF·교육별 합본 PDF·개별 수료증 ZIP·기관 제출 양식)를 고릅니다. 다음으로 연도·부서와 **내려받는 사유**를 고르면 해당 자료의 설정과 다운로드가 나타납니다. 사유를 고르지 않아 비활성인 버튼에는 이유와 **사유 선택으로 이동**을 안내합니다. 직원 개인정보가 든 자료라서 사유를 함께 기록하고, 관리자가 매달 접속기록을 점검할 때 확인합니다.

| 자료 | 내용 |
|---|---|
| 이수 현황 엑셀 | 요약(교육별·부서별 이수율), 직원별, 미이수자, 상세 내역(근거 이수증) 4개 시트 |
| 제출 양식에 채우기 | 올려 둔 엑셀 양식에 그대로 채움 ([8장](#8-제출-양식에-채우기)) |
| 이수증 ZIP | 교육별·부서별·개인별 폴더에 `부서_성명_교육명_이수일.pdf` |
| 개인별 합본 PDF | 직원 한 명당 이수증 PDF 한 파일로 모아 ZIP으로 받기. PDF 제목·파일명과 ZIP 파일 제목 수정 가능 |
| 교육별 합본 PDF | 교육 하나의 이수증을 부서·성명 순서로 한 파일에 |

- 확정한 이수증만 들어갑니다. 검수 대기가 남아 있으면 화면 위쪽에 알려 줍니다.
- 서무는 담당 부서 것만 받습니다.
- **개인별 합본 PDF**에서 전체 직원 또는 한 명을 고르고 제목을 수정합니다. 예: `{연도}년_{성명}_제출용` → `2026년_홍길동_제출용.pdf`. `{부서}`, `{사번}`도 사용할 수 있고, ZIP 파일 제목은 별도로 입력합니다. PDF의 원본 증명서 내용은 유지하며 문서 속성과 파일명에 제목을 반영합니다. 같은 통합과정 이수증은 한 번만 넣고, 같은 파일명은 번호로 구분합니다.

## 8. 제출 양식에 채우기

상급기관이나 부서에 내는 엑셀 양식이 따로 있으면, 빈 양식을 한 번 올려 두세요. 그다음부터는 그 양식 그대로 채워진 파일을 받습니다.

### 8-1. 양식 올리기

**내보내기 > 기관 제출 양식 > 양식 올리기·관리**(또는 `Ctrl` + `K` → "제출 양식")에서 빈 양식(.xlsx)을 올립니다.

![제출 양식 목록](images/forms.webp)

### 8-2. 찾은 자리 확인

프로그램이 양식에서 세 곳을 찾아 색으로 보여 줍니다.

- **파랑**: 머리글 줄 (성명·소속 같은 칸 이름. 두 줄로 합친 머리글도 읽습니다)
- **초록**: 사람을 한 줄씩 쓸 빈 줄
- **주황**: 합계·서명란 (사람이 늘면 그만큼 아래로 내려갑니다)

![찾은 자리](images/form-layout.webp)

틀렸으면 줄 번호를 고치고 **이 줄 번호로 다시 읽기**를 누릅니다.

### 8-3. 열마다 넣을 내용

열마다 무엇을 넣을지 프로그램이 골라 둡니다. 틀린 열만 고르면 됩니다.

- 사람: 연번, 성명, 부서, 직급, 사번, 생년월일, 직종, 아직 이수하지 않은 교육(비고 칸용)
- 교육: 이수 표시(O·X 등), 이수 상태, 이수일, 이수 시간, 과정명, 교육기관
- **이수 표시 모양**은 O/X, ○/×, 이수/미이수, Y/N 중에서 고릅니다. 부분이수는 미이수로, 대상 제외는 "-"로 씁니다.

아래 **미리보기**에 앞의 몇 명이 채워진 모습이 나옵니다. 양식 이름과 **쓰는 부서**(관리자는 "모든 부서 공용"도 가능)를 정해 **양식 저장**을 누릅니다.

![열 맞추기와 미리보기](images/form-columns.webp)

### 8-4. 받기

**내보내기**의 **제출 양식에 채우기**에서 양식을 고르고 **양식에 채워 받기**를 누릅니다.

- **미이수·부분이수 직원만**: 독려 명단을 양식으로 낼 때.
- **부서별 파일로 나누기 (ZIP)**: 전체 부서를 고른 경우 부서마다 파일을 따로 만듭니다.
- 양식에 `{기관명}` `{부서명}` `{연도}` `{작성일}` `{작성자}`라고 적어 두면 그 자리를 채웁니다.
- 합계 수식이 있으면 끼운 줄까지 범위를 늘리고, 엑셀이 열 때 다시 계산합니다.

![채워진 제출 양식](images/form-result.jpg)

**읽지 못하는 양식**

- 옛 엑셀(.xls): 엑셀에서 **다른 이름으로 저장**을 누르고 파일 형식을 **Excel 통합 문서**(.xlsx)로 바꿔 올리세요.
- 한글(.hwp) 양식, 한 사람이 여러 줄을 쓰는 양식, 한 시트에 표가 여럿인 양식은 아직 지원하지 않습니다.
- 그림·글상자가 있거나 다른 시트를 가리키는 수식이 있으면 저장할 때 주의 표시가 나옵니다. 받은 파일을 한 번 열어 보고 내세요.

## 9. 백업과 보관 (관리자)

**설정 > 백업·보관**에서 합니다.

- **자동 백업**: 하루에 한 번 DB 사본을 만들고, 원본 파일·쪽 이미지는 바뀐 것만 복사합니다. PC판은 그날 처음 켰을 때 `문서\이수모아 백업`에 만듭니다. **지금 백업**으로 바로 만들 수도 있습니다.
- 백업이 PC 안에만 있으면 PC가 고장 날 때 함께 잃습니다. 가끔 백업 폴더를 USB나 부서 공유 폴더에 복사해 두세요.
- **보관기간**: 이수증 자료(기본 5년), 접속기록(2년), 감사 로그(3년), DB 백업본 개수를 정합니다.
- **파기**: 보관기간이 지난 연도는 확인한 뒤 파기합니다. 되돌릴 수 없으니 필요하면 먼저 현황 엑셀을 받아 두세요. 파기 내역은 감사 로그에 남습니다.

그 밖의 설정 탭: **부서**, **사용자 계정**, **기관 정보**, **감사 로그**, **접속기록**(월 1회 점검 기록), **시스템 점검**(고칠 점 알림).

## 11. 자주 묻는 질문

**이수증을 올렸는데 검수함에 안 보여요.**
아직 읽는 중일 수 있습니다. 화면 위쪽의 "읽는 중" 안내와 대시보드의 **읽는 중** 숫자를 보세요. 세 번 시도해도 못 읽은 쪽은 올린 묶음 목록에 표시됩니다.

**이름을 다르게 읽었어요.**
스캔 상태가 나쁘면 비슷한 글자로 읽을 수 있습니다. 검수함의 **직원**에서 이름이나 사번으로 찾아 고르면 됩니다. 명단에 없는 이름이면 빨강 표시가 붙어 그대로 확정되지 않습니다.

**4대폭력 통합교육처럼 여러 교육을 한 번에 들었어요.**
인정할 교육에서 해당 교육을 모두 고르면 교육시간을 나눠 인정합니다.

**이수율 숫자가 생각보다 낮아요.**
**확정한 이수증만** 셉니다. 검수 대기가 남아 있는지 보세요. 휴직·파견 중인 직원은 대상에서 빠집니다.

**같은 사람이 같은 교육을 두 번 들었어요.**
둘 다 확정해도 됩니다. 시간 기준 교육은 시간을 더해서 판정합니다.

**비밀번호를 잊었어요.**
다른 관리자에게 **설정 > 사용자 계정 > 비밀번호 초기화**를 부탁하세요. 관리자가 한 명뿐이면 되찾을 수 없으니 관리자 계정을 둘 만들어 두기를 권합니다.

**제출 양식에서 열을 잘못 찾았어요.**
**제출 양식** 목록에서 **열 맞추기**를 눌러 언제든 고칠 수 있습니다.

## 0.5.0에서 추가된 기능

- **직원 명단 → 일괄 등록 → 빈 양식 다운로드**: 사번의 앞자리 0을 유지하는 빈 엑셀 양식입니다. 작성안내 시트에 필수 값과 날짜·재직 상태를 설명합니다.
- **신규 설치 기본 교육 16개**: 개인정보보호는 연 1시간입니다. 기존 설치의 교육 기준과 수료 기록은 자동으로 덮어쓰지 않습니다.
- **내보내기 → 최종 제출 명단 (16시트)**: 연도·부서를 고르고 충족 여부를 확인한 뒤 다운로드 사유를 선택합니다. 적용 교육 미달 또는 검수 대기가 있으면 해당 내용을 먼저 해결해야 합니다. 한 직원이 같은 교육을 여러 수료증으로 충족한 경우 증서별 행을 유지하며 이수 인원은 한 명으로 계산합니다. 현원은 빈칸입니다.
- **설정 → 업데이트**: 최신 버전 확인·다운로드·백업 후 설치를 제공합니다. 오프라인 설치 파일 검사도 지원합니다. 자세한 내용은 PC 설치 안내를 참고하세요.

기존에 보완한 수료증 인식·주제 충돌·중복 확인 규칙은 프로그램 코드와 교육 기준·과정 매핑으로 저장합니다. 새 설치에는 검증한 기본 과정 매핑을 제공하며, 사용자 PC에서 추가한 매핑과 자료는 백업 대상에 포함합니다. 개인 수료증을 모델에 자동 학습시키거나 외부로 보내는 방식은 아닙니다.


## ZIP으로 모은 수료증 올리기 (0.5.2)

수료증 올리기의 같은 입력 칸에서 ZIP을 선택하거나 끌어 놓으세요. 폴더 안의 PDF·JPG·JPEG·PNG를 찾아 개별 수료증으로 읽고 기존 검수함으로 보냅니다. 압축파일 처리 결과에서 꺼낸 파일 수와 건너뛴 사유를 보고, 아래 파일별 상태에서 중복·PDF 읽기 실패를 확인합니다. 같은 ZIP을 다시 올리면 기존 중복 확인과 끊긴 쪽 이어 올리기가 적용됩니다.

ZIP은 300MB 이하, 개별 파일은 100MB 이하이며 한 번의 선택에서 압축을 푼 수료증은 1,000개·500MB 이하입니다. ZIP 내부의 폴더·숨김 관리 파일을 포함한 항목은 5,000개 이하입니다. 암호가 걸린 항목, 중첩 압축, 다른 형식은 건너뜁니다. RAR·7z·분할 압축은 직접 풀어 지원하는 PDF·사진을 올려 주세요. 손상된 파일과 안전하지 않은 경로가 든 ZIP은 안내를 확인해 다시 준비하세요.

압축은 사용하는 브라우저에서 처리하고 개별 PDF·사진만 앱에 보관합니다. ZIP 자체를 보관하거나 외부 압축 해제 서비스로 보내지 않습니다. 최신 Edge·Chrome을 사용하세요.
