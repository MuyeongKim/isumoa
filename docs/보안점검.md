# 개인정보·보안 점검

2026-10-29, 0.5.1. 이 문서는 보안 검토 범위와 재검사 방법을 설명하며 악성코드 부재 인증서는 아닙니다.

## 데이터 처리와 외부 통신

직원 정보·수료증·읽은 글자·과정 연결·검수 결과는 설치한 PC의 데이터 폴더에 보관합니다. 수료증 OCR은 함께 배포한 모델을 사용하며 기본 엔진에 폐쇄망 모드를 설정하고 대체 엔진에도 로컬 한국어 데이터를 지정합니다. 모델을 가져오기 위해 수료증을 외부 서비스로 보내는 기능은 없습니다.

사용자가 업데이트 확인·다운로드를 누를 때 GitHub의 배포 정보와 EXE를 HTTPS로 받습니다. 이 요청에 직원·수료증·로그인 쿠키를 담지 않습니다. 설치 EXE의 주소·크기·SHA-256을 확인하고, 설치 전 백업하며 관리 권한과 PC 내 접속을 검사합니다. EXE는 아직 코드 서명이 없어 GitHub 배포 계정과 HTTPS·체크섬을 신뢰하는 방식입니다. 수동 EXE 검사는 공식 페이지의 해시를 별도로 대조해야 합니다.

개발·빌드 단계의 npm 패키지 설치, Node 공식 배포 파일과 보안 규칙·취약점 정보 조회는 업무 중 통신과 구분합니다.

## 0.5.1 보완

- 직접 접속하는 PC판 및 로그인 생략 모드에서 localhost·127.0.0.1·::1 이외의 Host를 거부해 DNS 재바인딩 경로를 차단합니다. 명시적 신뢰 프록시 설정을 사용하는 서버 구성은 보존합니다.
- 전용 요청 헤더와 함께 변경 요청의 Origin·Sec-Fetch-Site를 검사합니다. 같은 출처의 브라우저 요청 및 기존 PC 유지보수 도구를 지원합니다.
- 하이픈 없는 주민번호와 OCR 공백이 들어간 뒷자리를 읽은 텍스트에서 가립니다. 이전에 처리한 텍스트도 한 번 재검사하며 원본 파일과 증빙 이미지는 수정하지 않습니다.

## 재검사

개발 환경에서 `npm run security:check`로 알려진 배포 의존성 취약점과 인증·부서 권한·파일 접근·업데이트·개인정보 회귀 검사를 실행합니다. npm audit은 공개 패키지 의존성 목록을 레지스트리에 보내 알려진 취약점을 조회합니다. 실제 직원 명단과 수료증은 이 검사에 사용하지 않습니다.

소스 전체 Git 이력은 Gitleaks 같은 로컬 도구로 별도 검사합니다. 출시 시 최종 EXE를 추출해 원본과 해시를 대조하고 DB·계정·실제 수료증·개인 경로가 포함되지 않았는지 확인합니다.

## 남아 있는 확인 범위

- 원본 수료증·이미지에는 주민번호 등 원본의 개인정보가 남을 수 있습니다. DB·원본·백업은 앱 자체 암호화가 없으므로 Windows 계정과 기관의 디스크 암호화·백업 폴더 권한으로 보호해야 합니다.
- 알려진 취약점 0건이나 정적 검사 통과는 아직 알려지지 않은 취약점·공급망 악성 변경의 부재를 보증하지 않습니다.
- Windows 실기기 설치·업데이트·네이티브 라이브러리의 실제 통신·Microsoft Defender 검사는 별도로 확인해야 합니다. macOS의 코드 검토·패키지 검사·가상 자료 시험을 Windows 실기기 검증으로 표시하지 않습니다.
- 기관 네트워크나 외부 서버로 공개할 때는 해당 배포 환경의 인증·TLS·프록시·방화벽을 별도 검토합니다.
