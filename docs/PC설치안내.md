# 이수모아 — PC 설치 안내 (Windows)

이 PC에 설치해 혼자 쓰는 판입니다. 이수증과 직원 명단은 이 PC 안에만 저장되고, 인터넷이나 AI 서버로 보내지 않습니다.
스캔본도 프로그램 안의 OCR(kordoc, PP-OCRv5 한국어 모델)로 읽습니다.

## 1. 필요한 것

- Windows 10 또는 11, 64비트
- 디스크 여유 공간 2GB 이상 (프로그램 약 450MB + 이수증 자료)
- 관리자 권한은 필요 없습니다.

## 2. 설치

1. 받은 `이수모아-설치-버전-win-x64.zip`을 **오른쪽 클릭 → 모두 압축 풀기**로 풉니다.
   파일이 많아 압축 풀기에 몇 분 걸릴 수 있습니다. 압축 파일 안에서 바로 실행하면 설치되지 않습니다.
2. 푼 폴더의 **설치.bat**을 두 번 누릅니다.
   - 보안 경고("Windows의 PC 보호" 등)가 나오면 **실행** 또는 **추가 정보 → 실행**을 누릅니다. 인터넷에서 받은 서명 없는 내부용 스크립트라서 나옵니다.
3. "설치를 마쳤습니다" 창에서 **예**를 누르면 바로 실행됩니다.

설치되는 곳:

| 무엇 | 위치 |
|---|---|
| 프로그램 | `%LOCALAPPDATA%\Programs\isumoa` |
| 이수증 자료(DB·쪽 이미지)·설정·기록 | `%LOCALAPPDATA%\isumoa` |
| 백업 | `문서\이수모아 백업` |
| 바로가기 | 바탕화면·시작 메뉴의 **이수모아** |

## 3. 실행과 끄기

- 바탕화면의 **이수모아** 아이콘을 누르면 브라우저(Edge·Chrome)에 화면이 열립니다. 주소는 `http://127.0.0.1:47210` 이고, 이 PC에서만 열립니다.
- 처음 열면 기관명과 관리자 계정을 만듭니다. 비밀번호를 잊으면 되찾을 방법이 없으니 따로 적어 두세요.
- 쓰는 방법은 왼쪽 아래 **사용설명서**(또는 `Ctrl` + `K` → "사용설명서")를 누르면 새 창으로 열립니다. 인터넷 없이도 열리고, 인쇄해 나눠 줄 수도 있습니다.
- 브라우저 창을 닫아도 프로그램은 뒤에서 켜져 있습니다. 다시 아이콘을 누르면 바로 열립니다.
- 다 쓰고 나면 왼쪽 아래 **프로그램 끄기**를 누릅니다. 처리 중인 이수증이 있으면 마친 뒤 꺼집니다. PC를 끄거나 로그아웃해도 됩니다 (자료는 그대로 남습니다).

## 4. 백업

- 하루 중 프로그램을 처음 켰을 때 `문서\이수모아 백업`에 자동으로 백업합니다. **설정 > 백업·보관**에서 "지금 백업"도 됩니다.
- 백업이 이 PC 안에만 있으면 PC가 고장 날 때 함께 잃습니다. 가끔 이 폴더를 통째로 USB나 부서 공유 폴더에 복사해 두세요.

## 5. 업그레이드

새 판의 zip을 풀고 **설치.bat**을 실행하면 됩니다. 켜져 있는 프로그램을 끄고 프로그램만 바꿉니다. 이수증 자료와 설정은 그대로입니다.
제품 이름을 바꾸기 전(폴더 이름 `EduCert`)에 설치한 PC라면, 이수증 자료와 설정이 새 폴더(`%LOCALAPPDATA%\isumoa`)로 자동으로 옮겨지고 옛 프로그램 폴더는 지워집니다.

## 6. 제거

시작 메뉴의 **이수모아 제거** 또는 **설정 > 앱 > 설치된 앱**에서 "이수모아"를 제거합니다.
이수증 자료도 지울지 묻습니다. **아니요**(기본)를 누르면 자료를 남겨 두어 다시 설치하면 이어 씁니다. 백업 폴더는 지우지 않습니다.

## 7. 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 설치.bat을 눌러도 창이 잠깐 떴다 사라짐, "스크립트를 실행할 수 없습니다" | 기관 보안 정책이 PowerShell 스크립트를 막은 경우입니다. 정보화 담당에게 이 안내서와 함께 허용을 요청하세요 |
| "프로그램을 켜지 못했습니다" | 창에 나온 이유를 확인합니다. 포트를 다른 프로그램이 쓰면 `%LOCALAPPDATA%\isumoa\config.json`의 `port`(기본 47210)를 다른 숫자로 바꾸고 다시 실행합니다. 기록: `%LOCALAPPDATA%\isumoa\logs` |
| 설정 > 시스템 점검에 "tesseract로 읽고 있습니다" | 이 PC에 Visual C++ 재배포 패키지(x64)가 없어 기본 OCR을 띄우지 못한 경우가 많습니다. 정보화 담당에게 설치를 요청하면 다음 실행부터 기본 OCR로 읽습니다 (그동안도 사용은 됩니다) |
| 백신이 파일을 지웠다고 알림 | 정보화 담당에게 `%LOCALAPPDATA%\Programs\isumoa`를 예외로 등록해 달라고 요청한 뒤 다시 설치합니다 |
| 비밀번호를 잊음 | 관리자가 다른 관리자 계정으로 **설정 > 사용자 계정 > 비밀번호 초기화**. 관리자가 한 명뿐이면 되찾을 수 없으니, 관리자 계정을 둘 만들어 두기를 권합니다 |
