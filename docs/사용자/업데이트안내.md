# 프로그램·공식 규칙 업데이트

대상 배포판: **0.5.12**.

이수모아 0.5.10부터 **설정 → 업데이트**에서 프로그램 전체와 공식 검수 규칙을 함께 확인합니다. 설정 메뉴의 새 버전 표시를 눌러도 이 화면으로 이동합니다.

## 지금 확인하기

1. **모두 확인**을 누릅니다. 프로그램이나 규칙만 확인할 수도 있습니다.
2. 현재 버전·최신 확인 버전·마지막 확인 시도와 성공 시각을 비교합니다.
3. 프로그램은 **업데이트 받기 → 파일 검사 완료 → 업데이트 설치 → 백업 후 설치** 순서로 진행합니다. 자동 설치는 Windows PC 설치판에서 지원합니다. 수료증 읽기가 끝나야 설치할 수 있습니다.
4. 공식 규칙은 **규칙 변경 미리보기 → 이 규칙 적용**을 누릅니다. 서명·체크섬·호환 버전을 검사하며, 적용 전 추가·변경·삭제 내용을 확인합니다.

프로그램과 규칙의 버전은 따로 관리합니다. 새 규칙이 더 새로운 프로그램을 요구하면 **프로그램 업데이트 필요**로 표시하고 규칙 적용을 보류합니다. 필요한 프로그램을 먼저 업데이트한 뒤 다시 확인하세요.

## 자동 확인·알림 켜기

기본값은 **꺼짐**입니다. ‘실행할 때 하루 한 번 새 버전 확인’을 선택하고 **자동 확인 설정 저장**을 누릅니다. 오늘 자동 시도를 아직 하지 않았다면 저장 후 먼저 확인합니다.

이후 프로그램이 켜진 뒤 잠시 후 확인하고, 계속 켜 둔 PC는 다음 날짜에도 확인합니다. 날짜 기준은 한국 시간입니다. 실패한 날도 자동 시도는 한 번으로 제한하며, 필요하면 **모두 확인**으로 직접 다시 시도할 수 있습니다. 탭·창·프로그램 재시작으로 같은 날의 자동 조회가 반복되지 않도록 시도 날짜를 DB에 보관합니다.

새 버전이 있으면 관리자 설정 메뉴와 업데이트 탭에 건수를 표시합니다. 검수 중 팝업으로 작업을 중단하지 않습니다. **자동 확인은 다운로드·설치·규칙 적용을 하지 않습니다.** 설치 파일을 받고 준비하는 중에는 중복 확인을 보류할 수 있습니다.

옵션을 끄고 저장하면 이후 예약 확인을 중지합니다. 이미 시작한 조회는 마무리될 수 있습니다. 수동 확인 버튼은 계속 사용할 수 있습니다. 저장하지 않은 설정을 둔 채 이동하면 계속 수정·버리기·저장 후 이동 중 선택하도록 안내합니다.

## 연결에 실패했을 때

프로그램과 규칙의 결과를 각각 표시합니다. 한쪽이 실패해도 다른 쪽 확인 결과를 볼 수 있습니다. **확인하지 못함**을 ‘최신’으로 표시하지 않습니다. 이전에 성공한 정보는 ‘이전 확인 버전’과 성공 시각을 함께 남기며, 다시 확인해 갱신합니다.

업무 자료는 그대로 사용할 수 있습니다. 인터넷이 막힌 PC는 공식 EXE와 SHA256SUMS를 옮겨 설치 파일로 업데이트하고, 공식 규칙 JSON은 **검수 규칙 → 규칙 JSON 가져오기**를 사용하세요.

## 보존되는 자료와 통신 범위

사용자 규칙 편집·가져오기·내보내기·복원은 **검수 규칙**에서 관리합니다. 공식 규칙을 적용해도 사용자 규칙은 별도로 보존합니다. 직접 전체 교체나 복원을 선택한 경우에는 미리보기에 표시한 설정 변경이 적용됩니다. 기관 교육 기준·직원·기존 확정/제외 기록을 버전 확인만으로 바꾸지 않습니다.

확인은 GitHub 공개 배포 정보와 서명된 공식 규칙 파일만 조회합니다. 직원 명단·수료증·사용자 규칙·GitHub 로그인 정보는 전송하지 않습니다. 자동 확인 옵션·시도 날짜·성공/실패 정보는 DB 백업에 포함됩니다. 설치 전 백업·오류 시 복구 보호와 규칙 변경 미리보기는 유지합니다.

EXE는 현재 미서명입니다. Windows 실제 설치·업데이트·기관 백신 확인은 배포판의 검증 보고서와 별도 실기기 확인 절차를 참고하세요.
