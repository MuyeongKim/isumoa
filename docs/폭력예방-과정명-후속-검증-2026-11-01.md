# 4대 폭력 과정명 후속 보완 (2026-11-01)

기준 커밋: `87328e5`. 기존 동작의 안전 경계를 유지하면서 수료증 과정명 표기를 추가한다.

## 변경

- 연도와 `4대` 사이의 띄어쓰기·문장부호를 경계로 보존한다. `2026 4대폭력 예방교육`, `2026. 4대 폭력예방교육`, `(2026) 4대폭력예방교육`, `2026_4대폭력예방`을 인식한다. `4대·폭력`과 글자 사이의 공백도 처리한다.
- 과정명에 성희롱·성매매·성폭력·가정폭력이 모두 있고 `예방`이 있으면 전체 범위를 인정한다. `가정폭력·성폭력·성매매·성희롱 예방교육`도 해당한다. 본문만으로 전체 범위를 인정하지 않는다.
- 독립된 말로 쓰인 `사대폭력`을 지원한다. `십사대폭력`은 확대 인식하지 않는다.
- 기존 대기를 읽을 때 정확한 통합 연결의 `training-name-suggestion`과 오래된 `training-integrated-check`만 재평가한다. 후자는 기존 목록의 저장 flags에 남을 수 있어 함께 보완했다. 다른 경고와 연결 불일치는 유지한다. notes·flags·인정 연결·확정·제외 기록을 DB에 덮어쓰지 않는다.

`limitedViolenceTitle` 함수는 기존과 동일하다. 2~3개 주제, 일부·제외·택1·부분 이수·선택과정은 계속 확인 표시가 붙는다. `중앙부처`·`중급과정`은 그대로 인식하며, `14대폭력`·`24대폭력`·구분자 없는 `20264대폭력`은 신뢰 연결하지 않는다.

공식 `shared/defaultRules.json`과 서명 fixture는 변경하지 않았다. 버전·서명 흐름과 이전 확정 결과의 학습 매핑 사용 정책도 유지한다. EXE 버전 변경이나 원격 배포는 이번 범위에 포함하지 않는다.

## 검증

먼저 수정 전 테스트로 9개 실패를 재현했다. 표기 누락과 기존 경고 재평가를 확인한 후 수정했다.

- `npm run typecheck`: 통과
- `npm test`: 52개 파일, 576개 테스트 통과 (기존 550개 + 이번 26개)
- `npm run security:check`: 통과. 운영 의존성 취약점 0개, 보안 회귀 43개 통과
- `npm run eval -- --truth samples/certs/정답.json`: 기존 가상 검증 DB를 별도 위치로 복사하고 `ECP_CONFIG`로 지정해 실행. 모두 맞은 쪽 50/50, 표시 없이 틀림 0쪽. 직원·이수일·교육·시간 각각 48/48, 이수증 아님 표시 2/2로 이전 결과 유지

연도 뒤 `4대` 표기의 기존 대기를 목록·상세 API로 읽었을 때 두 파생 경고가 사라지고 저장된 certificate 행과 인정 연결은 동일함을 API 테스트로 확인했다. 단위 테스트는 확정·제외 상태, 다른 경고, 다른 인정 연결이 재평가로 바뀌지 않는 것도 확인한다.

평가는 복사한 가상 DB와 기존 OCR 캐시를 사용했다. 새 OCR 속도 평가, 실제 Windows 설치판 또는 Excel·한셀·Ollama 실사용 검증을 뜻하지 않는다. 운영 DB·직원·교육 기준은 건드리지 않았다.
