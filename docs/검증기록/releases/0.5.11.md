# 이수모아 0.5.11 검증 결과

검증일: 2026-11-01. 이전 공개 배포판 0.5.10 이후의 검수 사용성·과정명 인식 보완과 공모 항목에 맞춘 실행 안내를 포함합니다.

## 변경 내용

- 4대 폭력 전체 범위가 명확한 과정명을 신뢰 연결합니다. 연도·띄어쓰기·문장부호·전각 숫자·사대폭력 표기를 처리하며, 2~3개 주제·일부·제외·택1·전각/일반 혼용 숫자의 잘못된 범위는 확인 표시를 유지합니다.
- 기존 대기의 정확한 통합 연결에 남은 이름 비교·전체 범위 경고를 읽을 때 재평가합니다. 저장된 notes·수정값·확정·제외 기록을 자동 변경하지 않습니다.
- 현재 검색 결과 중 검수 대기이고 ‘이수증 아님’ 표시가 있는 쪽을 한 번에 제외합니다. 사유·감사 로그·원본을 보존하고 복원할 수 있습니다. 서버가 권한·현재 상태·판독 여부·경고를 재검사합니다.
- 이수 현황의 요약 표·직원 표에 오른쪽 교육 열이 더 있음을 알리는 가로 안내를 추가했습니다.
- 샘플 정답·생성기·평가 스크립트를 현재 통합교육 코드와 설치된 규칙에 맞췄습니다. 평가에서는 확정 이력의 학습 매핑을 사용하지 않습니다.
- Windows EXE 중심 README에 프로젝트 소개·접속 주소·실행 환경·설치·LLM 설정·모의자료·핵심 사용 순서·제약·개발 경위를 정리했습니다. 가상 모의자료 ZIP을 별도로 제공합니다.
- 기존 프로그램·공식 규칙 통합 업데이트, 기본 꺼짐인 자동 확인·알림, 사용자 규칙·선택형 로컬 AI 기능을 유지합니다.

프로그램의 분류 함수·화면 변경은 EXE 업데이트가 필요합니다. 공식 규칙 JSON과 서명 fixture는 변경하지 않았으며, 사용자 규칙·기관 교육 기준·기존 기록을 유지합니다.

같은 가상 자료의 최근 판독 평가: 직원·이수일·교육·시간 각각 **48/48**, 이수증 아님 **2/2**, 모두 맞은 쪽 **50/50**, 표시 없이 틀림 **0쪽**입니다. OCR 캐시를 사용하는 합성 표본 회귀이며 실제 모든 기관 서식의 정확도나 수작업 대비 시간 절감률을 뜻하지 않습니다.

실제 UI에서 새 직원 120명 등록, 11개 파일·50쪽 업로드, 폭력예방 20건 정상 일괄 확정, 이수증 아닌 2쪽 일괄 제외, 나머지 28건 확정, 1366×800 가로 안내, 명단 엑셀 다운로드를 확인했습니다. ExcelJS 읽기·ZIP CRC·XML 구문 검사로 16시트 XLSX 구조를 확인했습니다. 같은 파일·파일명만 바꾼 파일은 건너뛰고, 동일 수료증을 다른 PDF로 재저장한 경우에는 재확정을 차단했습니다. 자세한 시점·절차는 소스의 사용성·과정명 검증 보고서를 참고하세요.

## Windows에서 사용자가 확인할 항목

이 EXE는 **미서명 부서 시범운용용**입니다. macOS에서 Windows용 패키지를 만들고 정적 추출·PowerShell 유지보수 함수를 검사했습니다. 아래 항목은 Windows 실기기 결과와 구분합니다.

- [ ] Windows 10/11에서 설치 후 바탕화면 아이콘으로 실행
- [ ] 기관 보안 정책·백신에서 실행 허용 여부 확인
- [ ] 기존 설치판의 복사 자료로 업데이트 후 직원·기준·수료증·백업 보존 확인
- [ ] 실제 Excel·한셀에서 기관 제출 엑셀 열기·인쇄
- [ ] 종료·재실행·복원 확인
- [ ] 선택형 Ollama를 사용할 경우 설치 모델의 실제 응답 확인

실제 Windows 설치·업데이트, Windows Excel/한셀 열기·인쇄, 기관 백신, 실제 2종 LLM 비교는 미확인입니다. Windows 확인표와 직원 독립 사용 실측은 `docs/session1`에 준비되어 있습니다.

## 다운로드와 자료 보관

일반 사용자는 `isumoa-setup-0.5.11-win-x64.exe`를 사용하세요. Node.js·OCR 구성요소는 따로 설치하지 않습니다. 파일별 SHA-256은 함께 배포하는 `SHA256SUMS.txt`와 비교할 수 있습니다.

업데이트 전 설정 → 백업·보관에서 백업을 확인하세요. 기존 기관 정보·직원·교육 기준·원본·확정·제외·사용자 규칙을 보존합니다. DB·원본·백업은 앱 자체에서 자동 암호화하지 않으므로 PC와 백업 폴더 접근 권한을 관리하세요. 가상 모의자료는 시험용 환경에서 사용하고 실제 업무 자료와 섞지 마세요.
