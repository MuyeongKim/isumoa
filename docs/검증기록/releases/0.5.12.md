# 이수모아 0.5.12

2026-11-02. 제출 전 문서와 검수 사용성을 정리하고 Windows 설치 안내·ZIP 구성을 보완한 배포판입니다.

## 변경 내용

- **README 재구성:** 프로젝트 소개와 개발 경위, Windows 다운로드, 설치·실행, AI 구성, 모의자료 시연을 읽는 순서로 정리했습니다. LLM 없이 기본 업무를 사용할 수 있음과 자료 저장 위치, 모의 명단 120명 중 현황 대상 118명을 설명합니다. 실측·Windows·SmartScreen 자리표시는 유지합니다.
- **문서 폴더 정리:** `docs/사용자`, `관리자`, `개발`, `검증기록`으로 나누고 참조·프로그램 내 설명서 경로를 고쳤습니다. `npm run docs:check`로 저장소의 상대 문서·이미지 링크를 검사합니다.
- **제외 확인창 쪽 번호:** 이수증 아닌 쪽 일괄 제외와 일반 선택 제외에서 파일명과 실제 쪽 번호를 표시합니다. 확인창을 연 뒤 자료가 바뀌면 서버가 다시 확인하도록 요구합니다.
- **빈 업로드 묶음 정리:** 새 업로드에서 중복 파일만 골라 생긴 빈 묶음을 정리합니다. 파일이 하나라도 있거나 수신 중인 묶음은 보존하며, 관리자도 다른 사용자의 묶음을 정리하지 못합니다. 실제 정리 내역은 감사 로그에 남습니다.
- **설치 안내 파일과 바로가기:** 설치 폴더에 `PC설치안내.txt`를 포함하고 **시작 메뉴 → 이수모아 → 이수모아 설치 안내**로 엽니다. ZIP 최상위 안내도 유지합니다. 설치 실패 시 안내 바로가기를 원래 상태로 복구하며 새 업데이트 도우미의 기동 실패 복구에도 해당 바로가기를 포함합니다.
- **Windows ZIP 심볼릭 링크 제거:** 사용하지 않는 `node_modules/**/.bin`을 제거하고 나머지 내부 링크는 실제 내용으로 복사합니다. manifest 생성 시 남은 링크를 거부하고 완성 ZIP도 링크 0개를 확인합니다. 설치 시 크기·해시 검사는 그대로 유지합니다.

## 다운로드와 사용

- 심사용 Windows 설치 EXE는 프로젝트 열람 권한으로 받을 수 있습니다. [공공 GitLab v0.5.12 릴리스](https://gitlab.aigov.go.kr/tenmoo/isumoa/-/releases/v0.5.12)
- 압축 설치판과 시험 자료는 GitHub에서 받습니다. [Windows ZIP](https://github.com/MuyeongKim/isumoa-releases/releases/download/v0.5.12/isumoa-setup-0.5.12-win-x64.zip) · [가상 모의자료 ZIP](https://github.com/MuyeongKim/isumoa-releases/releases/download/v0.5.12/demo-samples-0.5.12.zip)
- 파일별 해시와 이전 배포 검증 기록을 확인할 수 있습니다. [GitHub 배포 기록과 SHA256SUMS](https://github.com/MuyeongKim/isumoa-releases/releases/tag/v0.5.12)

Node.js·OCR 구성요소를 따로 설치하지 않습니다. LLM이 없는 PC에서도 판독·검수·현황·출력을 사용할 수 있습니다. 설치 후 바탕화면의 이수모아를 열면 브라우저가 열리며 기본 주소는 PC 내부 주소인 `http://127.0.0.1:47210`입니다.

업데이트 전 **설정 → 백업·보관**에서 백업을 확인하세요. 기존 기관·직원·교육 기준·원본·확정·제외·사용자 규칙을 유지합니다. 공식 규칙과 서명 파일은 이번 프로그램 배포에서 변경하지 않습니다. DB·원본·백업은 앱 자체에서 암호화하지 않으므로 PC와 백업 폴더 접근 권한을 관리하세요.

모의자료는 직원 120명·8부서, PDF 11개·50쪽입니다. 휴직 1명·파견 1명이 현황 대상에서 빠져 대상은 118명이며, 정상 흐름의 결과는 확정 48건·제외 2건입니다. 모의자료는 운영 자료와 분리해 사용하세요.

## 검증 범위와 한계

반영한 변경의 상세 검증은 [문서 정리](../문서정리-2026-11-02.md), [검수·설명서 보완](../제출전-보완-2026-11-02.md), [설치 안내 파일](../설치안내-파일-2026-11-02.md), [배포판 링크 정리](../배포판-링크-정리-2026-11-02.md)에 기록했습니다. 해당 기록의 버전과 실행 시점은 유지합니다. 0.5.12 배포 파일의 검증 결과와 파일별 해시는 릴리즈의 `validation-report-0.5.12.md`와 `SHA256SUMS.txt`로 확인합니다.

0.5.11 ZIP에는 링크 항목과 manifest 크기·해시가 달라 Windows 압축 해제 방식에 따라 설치 검사가 실패할 수 있는 구성이 있었습니다. 0.5.12 ZIP은 수정된 링크 정리·검사 경로로 다시 만듭니다.

이 EXE는 **미서명 부서 시범운용용**입니다. Windows 10/11 실기기 설치·업데이트, 실제 시작 메뉴·메모장 실행, Windows PowerShell 5.1, Excel/한셀 열기·인쇄, 기관 백신 결과는 미확인입니다. macOS의 패키징·정적 추출·PowerShell 검사와 구분합니다. 실제 2종 LLM 비교와 직원 실측, 타 부서 독립 사용 결과도 아직 채우지 않았습니다.

이미 실행 중인 과거 업데이트 도우미는 소급 변경되지 않습니다. 새 설치 프로그램을 통한 정상 업데이트는 안내 파일·바로가기를 추가하지만, 과거 도우미의 최종 기동 실패 복구까지 이번 보강이 소급 보장하지는 않습니다.
